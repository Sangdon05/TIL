| 명령어                          | 설명                                             |
| ------------------------------- | ------------------------------------------------ |
| `git commit -m "메시지"`        | staging 상태의 변경 사항에 대한 커밋 메시지 입력 |
| `git commit --amend`            | 최근 커밋 메시지 수정 (에디터로 열림)            |
| `git commit --amend -m "메시지` | 최근 커밋 메시지 수정                            |
