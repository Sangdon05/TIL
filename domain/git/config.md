
| 명령어                                      | 설명                              |
| ---------------------------------------- | ------------------------------- |
| `git config --local user.name <사용자명>`    | 현재 저장소에서만 사용할 사용자명 지정           |
| `git config --local user.email <사용자명>`   | 현재 저장소에서만 사용할 사용자 email 지정      |
| `git config --global user.name <사용자명>`   | 현재 OS 사용자 계정에서 사용할 사용자명 지정      |
| `git config --global user.email <사용자명>`  | 현재 OS 사용자 계정에서 사용할 사용자 email 지정 |
| `git config --system user.name <사용자명>`   | 모든 OS 사용자 계정에서 사용할 사용자명 지정      |
| `git config --system user.email <사용자명>`  | 모든 OS 사용자 계정에서 사용할 사용자 email 지정 |
| `git config list` or `git config --list` | 현재 저장소의 환경 설정 내용을 표시한다.         |
