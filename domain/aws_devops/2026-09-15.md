#aws 

ubuntu
arm 아키텍쳐 (64비트 arm)

백엔드 서버는 대부분 2 ~ 4코어 메모리 4기가를 많이 사용한다.

- 키페어
	- RSA - PEM 키 생성
	- 한번만 생성할수있으니 백업 필수
- 네트워크 설정
	- 보안그룹
		- 기본 보안 그룹 선택 -> 여러 서버를 이용할때는 보안 그룹 분리 필요
		- 두가지 규칙
			- 인바운드
				- 사용자가 서버로 접속
				- 원격 접속 ssh 허용, 접속 아이피를 설정하면 허용 아이피 외에 접속 안됌
				- http, https 포트 허용
					- 80, 443 허용
						- 누구나 들어올수있도록 anywhere
						- ipv4, ipv6 추가
			- 아웃바운드
				- 서버에서 어떤 데이터가 나갈때  규칙
- 서버 저장공간
	- 프리티어는 30기가까지 늘릴수있음
- aws 공개 ip는 항상 바뀌기때문에 고정 ip로 연결해야한다.
	- 탄력적 IP(엘라스틱 ip) 주소 생성
