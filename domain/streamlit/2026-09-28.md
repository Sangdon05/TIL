## 설치

```
uv add streamlit
```

## 텍스트 요소
- `title`: 대제목
- `header`: 세션 제목
- `subheader`: 작은 제목
- `text`: 일반적인 글꼴 본문
- `caption`: 사진이나 표 밑에 들어가는 작고 옅은 색상의 설명 글
- `markdown`: 마크다운 문법
- `divider`: 화면에 가로로 얇은 선 표시
- `code`: 프로그래밍 코드를 작성할 때 사용하는 회색 박스(코드 블록)
	- `code(코드, language="언어명")`: 코드 뭉치를 선언한 언어명으로 하이라이팅 한다.
- `latex`: 수학 수식 랜더링

## 데이터프레임과 정적 테이블
- `metric`: 요약 지표
	- `label`: 이름
	- `value`: 현재 값
	- `delta`: 변화량(증가/감소)
- `dataframe`: 상하좌우 스크롤 가능, 데이터 정렬 기능이 있는 동적인 표
	- pandas로 값 적용
- `table`: 데이터 전체를 고정된 형태로 깔끔하게 렌더링, 데이터 양이 적을때 유용
	- pandas로 값 적용
- `data_editor`: 직접 값을 수정하고, 변경된 데이터를 다시 파이썬 코드에서 활용할수 있다.
- `json`: 데이터를 접었다 펼칠 수 있는 구조적인 형태로 랜더링

## 버튼 및 선택형 위젯
- `button`: 클릭 시 `True`로 인식하는 기본 버튼
	- `if button(버튼명)`: 버튼을 선택 시 True로 인식하며, 참일 경우의 코드가 실행된다.
- `download_button`: 클릭 시 파일을 내 컴퓨터로 저장
