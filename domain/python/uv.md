
| 명령어                      | 설명                                    |
| ------------------------ | ------------------------------------- |
| `uv init`                | 폴더 내에 uv 설정                           |
| `uv init <프로젝트명>`        | 프로젝트 명으로 폴더를 생성 후 uv 설정               |
| `uv add <패키지명>`          | python 패키지 추가                         |
| `uv remove <패키지명>`       | python 패키지 제거                         |
| `uv python pin <파이선 버전>` | 권장 파이선 버전 변경                          |
| `uv sync`                | 최초 저장소 clone 후 개발 환경 재구성 및 환경 변경사항 적용 |
| `uv run`                 | 스크립트나 명령어 실행                          |
