인덱스 연산자를 이용해 다차원의 값 슬라이싱
- `[0:2, 2:6]` - 0 ~ 1 행의  2 ~ 5열을 가져온다.

차원변경
- reshape: 원소수를 유지한 채 형상 변경 (-1 지정 시 나머지 차원 자동 계산)
- flatten: 다차원 배열을 1차원 배열로 평탄화

`arange(start, end)`: start 부터 end 미만까지 1차원 배열 생성

axis: 연산이 진행되는 방향
- axis=0: 세로 방향/열별 합
- axis=1: 가로 방향/행별 합
- `sum(axis=0)`: 행렬의 세로 방향으로 더하기

브로드캐스팅(Broadcasting) 연산
- 서로 크기가 다른 배열 간의 형상을 맞춰 자동 확장 연산 수행
- 스칼라 브로드캐스팅: `배열 + 5` -> 모든 요소에 일괄 적용

행렬 전치: 연산이 진행되는 방향 기준
- 2차원 배열의 행과 열을 서로 맞바꾸는 작업
- 주 대각선 요소를 교환 m x n -> m x n 행렬로 변환
```python
import numpy as np

# 2x3 행렬 생성
matrix = np.array([[1, 2, 3], [4, 5, 6]])

# 전치행렬 구하기
transpose_matrix = matrix.T
print(transpose_matrix)
```

```
[[1 4] [2 5] [3 6]]
```

행렬곱 (`@`): 선형대수 규칙에 따라 앞 행렬의 행과 뒤 행렬의 열을 내적한다.
- 선형대수 규칙
	- 차원 일치: 앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 곱셈이 가능하다.
	- 결과 크기: m x k 행렬과 k x n 행렬의 곱 결과는 m x n 행렬이 된다.
- 내적: 두 벡터의 같은 위치에 있는 성분들을 각각 곱한 후 그 결과들을 모두 더하여 하나의 스칼라(숫자) 값으로 만드는 것
