
| 단축키           | 설명                              |
| ------------- | ------------------------------- |
| shift + enter | 선택된 혹은 수정중인 셀 실행 후 아래에 새로운 셀 추가 |
| ctrl + enter  | 선택된 혹은 수정중인 셀 실행                |
| a             | 셀 위로 새로운 셀 추가                   |
| b             | 셀 아래로 새로운 셀 추가                  |
| y             | 선택된 셀을 python code 셀로 변경        |
| m             | 선택된 셀을 markdown 셀로 변경           |
