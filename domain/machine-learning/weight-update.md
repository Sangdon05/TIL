한글: 가중치 업데이트

$$
w_{new} = w_{old} - \alpha(\frac{\partial J}{\partial w})
$$
- $w_{new}$: 다음번에 모델이 시도할 새로운 가중치
- $w_{old}$: 지금 모델이 시도중인 가중치
- $\alpha$: 학습률(Leaning Rate), 개발자가 직접 설정하는 값
- $\frac{\partial J}{\partial w}$: 기울기(Gradient), 현재 가중치의 경사도
	- 가중치 $w$를 아주 미세하게 변화시켰을 때, 전체 오차 $J$가 얼마나 변화하는가를 나타내는 순간 변화율
- $J$: 손실 함수(Loss Function), 현재 모델이 내린 예측값과 정답 사이의 오차(Error)를 나타내는 함수
	- 모델의 성능이 나쁠수록 값이 커지고, 모델이 ㅁ완벽하게 맞출수록 값은 0에 수렴한다.
- $\partial$: 라운드 디(Round D), 여러개의 변수가 있는 함수에서 특정 변수 하나에 대해서만 미분하겠다는 **편미분**의 기호
	- 가중치 업데이트 식에서는 다른 파라미터(예: $b$ 바이어스)를 고정해두고, 오직 $w$의 변화에만 집중하겠다는 의미
