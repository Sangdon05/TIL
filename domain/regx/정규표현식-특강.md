- 정규 표현식 (Regular Expression)
	- 데이터의 패턴을 표현하는 식 -> 표현 방법

- `메타문자`: 특별한 의미, 특별한 기능을 가진 문자
	- ```python
	. ^ $ * + ? { } [ ] \ | ( )
	```
	- Dot(`.`) 문자와 반복(`, +, {m,n}, ?`)
		- `패턴{n}`: 패턴을 n번 반복
		- `패턴{m,n}`: 패턴이 m번 이상 n번 이하 매칭
		- `패턴{m,}`: 패턴이 m번 이상 반복
		- `패턴+`: `패턴{1,}`과 동일, 1번이상 반복하는 패턴 (한번은 꼭 있어야 한다.)
		- `패턴*`: `패턴{0,}`과 동일, 0번이산 반복되는 패턴 (없어도 되고 1개 이상있어도 된다.)
		- `패턴?`: `패턴{0,1}`과 동일. 없어도 되고 있어도 되지만 있다면 1개만 있어야함
		- `.`: 줄 개행문자(`\n`)을 제외한 모든 문자
		- `^패턴`: 패턴으로 시작하는 패턴
		- `패턴$`: 패턴으로 끝나는 패턴
		- `패턴|패턴`: or로 여러 문자중 매치
			- `compile("banana|apple|melon)`: apple, banana, melon 중 일치 매칭
- 문자 클래스
	- `[abc]`: 문자 a 또는 b 또는 c에 매칭되는 패턴
	- `[a-z]`: 문자 a부터 z까지 매칭되는 패턴
	- `[0-9]`: 숫자가 포함되어 있으면 매칭되는 패턴
	- `[^0-9]`: 숫자가 아닌 패턴
	- `[^a-z]`: 알파벳 소문자가 아닌 패턴
	- 단축 표기법
	    - `\d`: `[0-9]`와 동일
	    - `\D`: `[^0-9]`와 동일, 숫자가 아닌 문자 1개
	    - `\s`: 공백문자 한개 (공백 1개, `\t`, `\n`, `\r`, `\f`)
	    - `\S`: 공백이 아닌 문자 1개
	    - `\w`: `[a-zA-Z0-9_]`와 동일, 단어 한개
	    - `\W`: `[^a-zA-Z0-9_]`와 동일
	    - `\b`: 단어 구분자
	    - `\B`: 단어 구분자가 아님
- python re 모듈 사용법
	- 문자열 검색 메서드
		- `match()`: 문자열의 처음부터 매치되는지 조사
		- `search()`: 문자열 전체를 검색
		- `findall()`: 매치되는 모든 문자열을 리스트로 리턴
		- `finditer()`: 매치되는 모든 문자열을 match 객체의 iterator로 리턴
	- match 객체의 메서드 (group, start, end, span)
		- `group`: 패턴에 매치된 내용
		- `start`: 패턴에 매치된 시작 위치
		- `end`: 패턴에 매치된 끝위치
		- `span`: 패턴에 매치된 시작, 끝 위치를 튜플로 반환
- 컴파일 옵션
	- `DOTALL` or `S`: `.`이 `\n`을 포함한 모든 문자와 매치되게 해야할때 사용
		- `compile(패턴, DOTALL)`, `compile(패턴, S)`
	- `IGNORECASE` or `I`: 대소문자 구별 없이 매치되게 해야할때 사용
		- `compile(패턴, IGNORECASE)`, `compile(패턴, I)`
	- `MULTILINE` or `M`: `^`, `$`를 각 줄마다 적용하여 매치되게 해야할때 사용
		- `compile(패턴, MULTILINE)`, `compile(패턴, M)`
		- 줄 개행마다 적용된다.
- 그루핑 (Grouping)
	- 특정 부분의 문자열만 뽑아내거나 반복을 묶을 때 `()`를 사용
	- 인덱스로 특정 문자열 추출
		- `패턴(그룹 패턴)패턴`: 검색 결과에서 `group(1)`로 추출 가능
	- 그루핑된 문자열 재참조
		- `(패턴)패턴\1`: 그룹핑된 인덱스로 재참조
		- `?P=<키워드>패턴(?P=키워드)`: 그룹핑 키워드로 재참조하여 패턴 탐색
	- 그룹에 이름 붙이기
		- `(?P=<키워드1>패턴)패턴(?P=<키워드2>패턴)`
- 전방 탐색 (Lookaround)
	- `?=패턴`: 긍정형 전방 탐색
	- `?!패턴`: 부정형 전방 탐색
- 문자열 바꾸기 (sub, subn)
	- 정규식과 매치되는 부분을 다른 문자로 변경
		- `sub`
			- 바꾸기 횟수 제어
				- `sub(대치문자, 문자, count=횟수)`: 문자에서 매치되는 부분 중 횟수 만큼 대치문자로 변경
		- `subn`: 결과를 튜플로 리턴 `(결과 문자열, 횟수)`
	- sub 메서드에서 참조 구문 사용하기
		- 그룹핑을 사용하여 원하는 그룹 패턴에 문자를 변경한다.
	- sub 메서드에 매개변수로 함수 넣기
		- ```python
			  def hexrepl(match):
			    value = int(match.group())
			    return hex(value)
			
			p = re.compile(r'\d+')
			print(p.sub(hexrepl, 'Call 65490 for printing, 49152 for user code.'))
			# 'Call 0xffd2 for printing, 0xc000 for user code.'
		  ```
- Greedy vs Non-Greedy
	- Greedy 방식 (가장 큰 범위 매치)
		- `패턴.*패턴`: 기본적으로 `*`은 가장 큰 범위로 매치한다.
	- Non-Greedy 방식 (최소한의 범위 매치)
		- `패턴.*?패턴`: 가장 가까운 범위로 매치한다.

## 용어 사전

| **용어**               | **영어 표현**                    | **설명**                                                                                           |
| -------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------ |
| **정규 표현식**           | Regular Expression           | 텍스트 내에서 특정한 규칙(패턴)을 가진 문자열을 찾거나 조작하기 위해 사용하는 형식 언어                                               |
| **메타 문자**            | Meta Characters              | 정규 표현식 구문 내에서 단순 텍스트 데이터가 아닌 특수한 제어(반복, 위치, 논리 등) 기능을 수행하는 기호                                    |
| **문자 클래스**           | Character Class              | `[ ]`로 묶인 집합 안의 어떤 문자와도 매치될 수 있도록 정의한 문자열 집합 규칙                                                  |
| **컴파일 옵션**           | Compile Options              | `re.DOTALL`, `re.IGNORECASE` 등 정규식 객체를 생성할 때 탐색 동작 방식(대소문자 무시, 줄바꿈 포함 등)을 제어하는 설정                |
| **그루핑**              | Grouping                     | 정규식의 일부를 `( )`로 묶어 하나의 단위로 처리하고, 전체 매치 결과 중에서 특정 부분만 분리하여 추출할 수 있게 하는 기능                         |
| **전방 탐색**            | Lookaround                   | 긍정(`(?=)`) 또는 부정(`(?!)`) 조건을 주어 매치 여부를 판단하지만, 매치된 문자열을 결과에 포함(소비)하지 않고 조건으로만 사용하는 기법             |
| **문자열 치환**           | Substitution (`re.sub`)      | 대상 문자열에서 정규식 패턴과 일치하는 부분을 찾아 지정한 다른 문자열이나 함수의 반환값으로 교체하는 작업                                      |
| **Raw String**       | Raw String (`r"..."`)        | 파이썬 문자열 리터럴 규칙의 이스케이프 시퀀스(예: `\b`, `\n`) 문제를 피하기 위해, 문자열 앞 `r`을 붙여 백슬래시(`\`)를 문자 그대로 취급하게 하는 표기법 |
| **탐욕적 매칭 / 비탐욕적 매칭** | Greedy / Non-greedy Matching | 가능한 가장 긴 문자열을 찾아 매치(Greedy)하는 기본 동작을 `?` 기호를 활용해 조건을 만족하는 가장 짧은 문자열만 매치(Non-greedy)하도록 변경하는 개념   |
