## 웹문서
- 뼈대: HTML (Hyper Text Markup Language)
	- 페이지 이동 가능 (Hyper Text)
	- 태그로 구성 (Markup)
	- `<태그명>내용</태그명>`: `<태그명>` 여는 태그, `</태그명>` 닫는 태그
	- 단일 태그: `<태그이름>`
	- 확장자: `.html`, `.htm`
- 스타일링: CSS (Cascading Style Sheet)
	- 상위요소의 스타일이 하위요소에 전달된다. (Cascading)
	- 확장자: `.css`
- 동적요소: JavaScript
	- 확장자: `.js`

## HTML
- 웹표준 (Web Standards)
	- 어떤 브라우저를 사용해도 동일한 화면, 동일한 기능으로 동작해야한다.
- 기본 구성
	- `<!DOCTYPE html>`: HTML 버전 태그
	- `<html>`: 문서의 시작
		- `<head></head>`: 문서의 정보, 문서 자원에 대한 정의 (CSS, JS 등)
			- title, meta, ...
		- `<body></body>`: 문서의 출력
	- `</html>`: 문서의 종료
- 태그 (문서와 관련성이 높다.) -> 요소(elements)
	- 제목 태그 (Heading)
		- `<h1>` ~ `<h6>`
			- h1: 주제목
			- h2: 하위제목
			- ...
	- 본문 서식 태그
		- `<p>`: 문단 태크
		- `<b>` or `<strong>`: 두꺼운 폰트
		- `<i>`: 기울임체
		- `<u>`: 밑줄
		- `<del>` or `<strike>`: 취소선
		- `<br>`: 개행
- 주석
	- 설명
	- 출력 배제
	- `<!-- -->`: 설명, 출력을 배제한 코드
- 문단 태그 (Block 속성)
	- 줄 개행됨
	- `<p>`, `<div>`, `<h1>` ~ `<h6>`, `<from>`, ...
	- div 태그를 자주 사용
	- 공간을 가진다. (너비, 높이를 설정 가능)
- 글 태그 (Inline 속성)
	- 줄 개행하지 않음
	- `<i>`, `<b>`, `<strong>`, `<a>`, `<u>`, `<span>`, ...
	- span 태그를 자주 사용
	- 공간을 가지지 않는다. (너비, 높이 결정하지 못함)

## 하이퍼링크
페이지 간의 이동

- `<a>`: 하이퍼링크 태그
	- 태그의 추가 정보: 속성 (attribute) - 태그의 기능을 수행하기 위한 정보
		- `href`: 이동할 경로
			- 절대경로: 전체 URL 혹은 전체 파일 경로
				- 경로가 변경되면 출력이 안된다.
			- 상대경로
				- `./`: 현재 파일이 있는 폴더 경로
				- `../`: 현재 파일이 있는 폴더의 상위 폴더 경로
		- `target`: 출력할 창의 위치 
			- `_self` (기본값) -> 현재 창
			- `_blank` -> 새로운 창
			- `_parent` -> 부모창
				- `<iframe>`내의 내용이 자식으로써 iframe이 있는 창을 부모창으로 인식한다.
					- `src`: 창에 출력할 경로 (URL)
					- `name`: 창의 이름 지정
			- `_top` -> 가장 상위에 있는 창
			- `창의 이름` -> `name`이 설정된 창으로이동

## 양식 태그

- `<form>`: 양식 태그
	- `<input>`: 입력을 받기위한 태그
		- `action`: 제출 처리 URL
		- `type`: 입력 유형
			- `text`: 기본값
			- `password`: 비밀번호 마스킹 표시
			- `radio`: 여러개중 한개만 선택
			- `checkbox`: 여러개중 여러개 선택
			- `submit`: 양식 제출
			- `reset`: 입력 항목 초기화
			- `button`: 일반 버튼
		- `name`
			- `radio`와 `checkbox`의 그룹 명칭

## LLM

- LLM의 주요 한계
	- 환각 (Hallucination)
	    - LLM은 분류 모델(다음 토큰에 대한 분류 모델)
	- 지식 컷오프 (Knowledge Cutoff)
	    - 학습을 완료한 시점 이후의 지식에 대해서는 답변이 올바르지 않다.
	- 비결정성 (Non-determinism)
	    - 같은 질문을 해도 다른 답변이 나올 수 있음
	- 편향 (Bias)
	    - 학습 자료가 의도치 않게 편향된 시점으로 바라볼 경우 편향된 시점을 학습한다.
- 환각 방지 프롬프트 및 temperature 제어
	- `top-k`, `top-p`, `temperature`
	- `top-k`: 가장 높은 확률의 k개 만큼의 토큰을 선택, 선택된 토큰을 응답으로 사용
	    - 예) `top-k = 100` -> 가장 높은 확율인 토큰 100개 중에서 선택
	- `top-p`: p 확률 이상의 토큰에서 선택
	- `top-p` + `top-k`를 같이 사용해서 환각을 줄인다.
	- `temperature`: 확률 분포 조정 (0에 가까울수록 정확한 답변, 1에 가까울 수록 창의적인 답변)
	    - 0에 가깝게 설정: 도구선택, 형식의 고정
- 역할별 메시지 템플릿 조립하기
	- System: 모델의 역할 (페르소나), 상황, 과업, 규칙 정의, 최우선순위 -> `SystemMessage`
	- User: 실제 질의 응답에 대한 사용자 질문, 처리할 데이터의 전달, 가변적, 프롬프트 템플릿 -> `HumanMessage`
	- Assistant: AI가 출력한 응답 -> `AIMessage`
	- User + Assistant -> 대화의 맥락 정보를 쌍으로 전달
	    - 1쌍 - 턴
	    - 여러쌍 - 멀티 턴
	- `BaseMessage`의 하위 클래스(`HumanMessage`, `SystemMessage`, `AIMessage`, `ToolMessage`)
