## 서브쿼리

- SELECT `___` : 스칼라 서브쿼리
- FROM `___` : 인라인뷰
- WHERE `___` :
	- 단일행 서브쿼리 (비교 연산)
	- 다중행 서브쿼리 (IN, NOT IN, EXISTS)
	- 상관 서브쿼리 : 내부 질의 결과를 외부 질의에 사용

## ACID 원칙 : 트랜잭션 4가지 원칙
>트랜잭션: SQL 실행 단위

- A - Atomicity 원자성
	- 모두 성공 또는 모두 실패
- C - Consistency 일관성
	- 규칙(제약조건)을 위반 방지
- I - Isolation 격리성 
	- 동시 트랜잭션이 서로 간섭 방지 (동시성 문제)
	- `SELECT ___ FOR UPDATE`: DB Lock
- D - Durability 지속성
	- COMMIT으로 DB에 영구적 반영

트랜잭션
- `BEGIN;`: 트랜잭션 시작
- `COMMIT;`: 트랜잭션 종료 (DB에 반영)
- `ROLLBACK;`: 트랜잭션 복구 (`COMMIT` 전에만 가능)
