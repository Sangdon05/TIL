DML
- SELECT
	- `SELECT [ALL|DISTINCT] <컬럼>[, ...] FROM <테이블명>[, ...] [WHERE <조건식>] [ORDER BY <컬럼명> [ASC|DESC][, ...]] GROUP BY <컬럼명>[, ...] [HAVING <집계함수 조건]`
		- ALL: 기본값, 중복을 포함한 전체
		- DISTINCT: 중복없이 조회
		- WHERE: 조건식, 조회의 범위를 좁힌다.
			- 비교연산자: `<`, `>`, `>=`, `<=`
			- 논리 연산자: `AND`, `OR`, `NOT`
			- `IN`: 포함 여부
			- `NOT IN`: 포함되지 않았을 떄
			- `BETWEEN A AND B`: A ~ B 사이
			- `IS NULL`: 값이 빈 상태인지 체크
			- `IS NOT NULL`: 값이 있는 상태인지 체크
		- `CASE WHEN THEN ELSE END AS`: 조건에 따른 다른 값을 부여하는 경우
			- 필드를 명시하는 위치에 적용 (FROM 절 앞쪽)
			- ```sql
			  SELECT CASE WHEN <조건식>[, ...] THEN <결과>
						   WHEN <조건식>[, ...] THEN <결과>
						   ELSE <결과>
					  END AS <새로운 컬럼명>
			  ```
				- `ELSE`: 모든 조건이 거짓일떄 값
		- `ORDER BY`: 정렬
			- ASC: 오름차순, 기본값
			- DESC: 내림차순
		- `GROUP BY`
			- 특정 컬럼의 같은값을 기준으로 그룹을 만든다.
			- 집계함수와 함께 사용하는 경우가 많다.
			- 레코드 개수는 그룹핑 되어있는 결과 갯수만큼 조회 된다.
			- 조회 컬럼은 반드시 `GROUP BY` 절에 명시된 컬럼만 사용 가능하다.
			- 집계 함수를 포함한 조건은 절대 `WHERE` 절에서 사용 불가능하다.
		- `HAVING`: 집계함수 조건
	- 구문 실행 순서
		- FROM이: 먼저 실행
		- WHERE: 두번째 실행
		- ORDER BY: 세번째 실행
		- SELECT: 마지막 실행
	- `NULL`은 값이 없는 상태이므로 비교, 산술 등의 연산 불가
	- `AS`: 별칭
		- 컬럼명 뒤 -> 다른 컬럼명으로 임시 지정
		- 테이블명 뒤 -> 다른 테이블명으로 임시 지정
		- 자주 사용하는 것이라 생략 가능
			- `<테이블명> AS <별칭>` -> `<테이블명> <별칭>`
	- `LIKE`: 키워드 검색
		- `LIKE <키워드>`: 키워드와 정확히 매칭
		- `LIKE [%]<키워드>[%]`: 
			- 와일드 카드가 뒤에만 있을 경우`<키워드>%`: 키워드로 시작하는 패턴
			- 와일드 카드가 앞에만 있을 경우 `%<키워드>`: 키워드로 끝나는 패턴
			- 와일드 카드가 앞뒤 모두있을 경우 `%<키워드>%`: 키워드가 포함된 패턴

## 통계 (집계)

집계 함수
- `COUNT(컬럼명)`: 레코드 갯수
	- `*`: 전체 컬럼에 대한 레코드 갯수
- `SUM(컬럼명)`: 합계
- `AVG(컬럼명)`: 평균
- `MIN(컬럼명)`: 최소값
- `MAX(컬럼명)`: 최대값

## 테이블 결합

집합: 중복을 허용하지 않는다.
- 합집합 (`UNION`): 중복은 제거하고 합친다.
	- `UNION ALL`: 중복을 허용한다.
- 교집합 (`INTERSECT`): 공통적인 것
- 차집합 (`EXCEPT`)

JOIN: 두테이블에서 공통적인 값을 기준으로 테이블을 하나처럼 조회되도록 결합해 주는 것
- `[INNER] JOIN`: 동등 조인, 내부 조인 (교집합)
	- `INNER` 키워드는 생략 가능
- `OUTER JOIN`: 외부 조인
	- `<주 테이블> LEFT [OUTER] JOIN <보조 테이블>`: 주 테이블 모두 출력, 보조 테이블은 있는 것만 출력
	- `<보조 테이블> RIGHT [OUTER] JOIN <주 테이블>`: 주 테이블, 보조 테이블 모두 출력
	- `FULL OUTER JOIN`: 양쪽 모두 주 테이블로 모두 나온다.
	- `OUTER` 키워드 생략 가능

LIMIT
- `LIMIT 조회할 행수 [OFFSET <시작 인텍스 번호>]`
