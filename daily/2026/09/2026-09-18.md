## 반응형 설정

- 뷰포트(Viewport): 보이는 화면
	- `width`
		- `device-width`: 장비의 너비 기준
		- `device-height`: 장비의 높이 기준 (모바일이 가로로 되었을때)
	- `user-scalable`
		- `yes`: 확대/축소 가능
		- `no`: 확대 축소 불가능
	- `minimum-scale`: 축소 비율
	- `maximum-scale`: 확대 비율
	- `initial-scale`: 처음 화면 비율
- 단말기 플랫폼 브레이크 포인트: CSS 적용이 달라진다.
	- 모바일: ~ 767px
	- 태블릿: 768px ~ 1023px
	- 데스크탑: 1024px ~
- 미디어 쿼리 (`@media ...`)
	- `media 미디어 타입 and (미디어 특성) { css 정의 }`
		- 미디어 타입: 장비 종류
			- `screen`: 컴퓨터 모니터, 태블릿, 스마트폰
			- `print`: 프린트에만 해당하는 css
			- `speech`: 시각 장애인용 스크린 리더 css
			- `all`: 기본값
		- 미디어 특성: 브레이크 포인트 설정을 주로 지정
			- `width`, `height`: 특정 높이, 너비
			- `min-width`: ~ 크기 이상
			- `max-width`: ~ 크기 이하
			- `orientation`: 기기의 방향
				- `portrait`: 세로 방향
				- `landscape`:가로 방향
