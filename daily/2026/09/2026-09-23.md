## 객체 리터럴

- 자바스크립트 객체
	- 원시타입: 재료가 되는 값 - 숫자, 문자, 논리값 등
	- 객체타입: 원시타입 외 모든 객체
- 속성 (Property)
	- 접근
		- 마침표(`.`) 연산자: 속성명이 변수명 규칙을 따르는 경우
		- 대괄호(`[]`) 연산자: 속성명이 변수명 규칙을 따르지 않는 경우
	- 추가
		- 새로운 속성명으로 값 대입
	- 수정
		- 이미 있는 속성명으로 값 대입
	- 삭제
		- `delete` 객체참조변수, 속성명

## 함수

- `function`
	- 함수명: 함수 객체의 이름표 (변수와 같다.)
- 함수의 실행 평가 과정
	- 실행 가능한 객체(*EC (Execution Context) 객체*)로 함수를 번역하는 과정
- 유효범위 체인 (Scope)
- `this` 바인딩: 호출 시 함수를 호출한 객체 주소

## 객체 상속

- 프로토타입(prototype) 기반의 객체간의 상속: 프로토타입 체인
- 상성자 함수
	- 객체를 생성하는 함수
	- 네이밍 관례: 첫글자를 대문자 (PascalCase)
	- new 연산자
- 생성자 함수가 객체를 생성하는 과정
	- 생성자 함수의 prototype 객체 상속
	- 생성자 함수의 `this`를 생성된 객체의 주소로 변경하고 호출
	- 함수 정의는 prototype 객체에 추가하는게 일반적 - 리소스 절약
- 생성자 prototype 메서드
	- 객체가 생성이되면 공유할 목적의 메서드 (인스턴스 메서드, instant method)
- 생성자 메서드
	- 객체 생성없이 공유하는 메서드 (정적 메서드, static method)
- 데이터 프로퍼티
	- `value`: 값
	- `writable`: 변경 가능 여부
	- `enumerable`: 열거 가능 여부
	- `configurable`: 재정의 가능
		- 설정을 변경할 수 있는가?
		- `false` 시 삭제도 불가
- 참고 즉시 실행 함수: 정의 -> 즉시 호출
- `Object.seal()`: 객체 밀봉
	- 속성 추가 불가
	- 속성 삭제 불가
	- 속성 변경 가능
- `Object.freeze()`: 객체 동결
	- 속성 추가 불가
	- 속성 삭제 불가
	- 속성 변경 불가
- 접근자 프로퍼티
	- `get`: 읽기
	- `set`: 쓰기
	- `enumerable`: 열거 가능 여부
	- `configurable`: 재정의 가능 여부

## 직렬화 (Serialization)

- JSON 객체
	- 자바스크립트 객체 -> JSON 문자열 (직렬화)
		- `sringify()`
	- JSON 문자열 -> 자바스크립트 객체 (역직렬화)
		- `parse()`
