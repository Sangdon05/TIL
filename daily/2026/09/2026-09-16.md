## CSS 선택자

- 기본 선택자
	- 전체 선택자
	- 태그 선택자
	- 클래스 선택자
	- 아이디 선택자
	- 우선순위
		- 전체 선택자 < 태그 선택자 < 클래스 선택자 < 아이디 선택자 < element style 속성
- 복합 관계 선택자
	- 하위 선택자 (조상 자손)
	- 자식 선택자 (부모>자식)
	- 형제 선택자 (형~동생)
	- 인접 형제 선택자 (형+동생)
	- 그룹 선택자 (,)
	- 속성 선택자
		- `[속성]`: 지정된 속성이 있으면 선택
		- `선택자[속성]`: 다른 선택자와 조합을 통한 선택 사용
		- `[속성명=값]`: 속성의 값이 일치하는 요소 선택
		- `[속성명^=값]`: 속성의 값으로 시작하는 요소
		- `[속성명$=값]`: 속성의 값으로 끝나는 요소
		- `[속성명*=값]`: 속성의 값이 포함된 요소
- 가상 클래스 선택자: `선택자:상태, 조건, 위치`
	- 가상 선택자: 위치
		- 자식 요소는 타입이 달라도 선택
			- `:first-child`: 첫번째 자식 요소
			- `:last-child`: 마지막 자식 요소
			- `:nth-child`
				- `:nth-child(숫자)`: 숫자 위치에 있는 요소 선택 (`:nth-child(1)`)
				- `:nth-child(수식)`: 수식에 해당하는 요소 선택 (`:nth-child(2n+1)`)
		- 같은 타입만 선택
			- `:first-of-type`
			- `:last-of-type`
			- `:nth-of-type`
			- `:only-of-type`: 자식 요소가 1개만 있는 경우 선택
	- 조건 선택자
		- `:not(선택자)`: 지정된 선택자가 아닌 요소 선택
		- `:is(선택자1, 선택자2, ..) 자식 선택자`:  상위요소를 선택
	- 상태 선택자
		- `:hover`: 마우스가 요소에 올라간 상태
		- `:focus`: 특정 요소가 선택된 경우, 커서(input, ..)가 있는 상태
		- `:checked`: 체크된 형태
		- `:readonly`:읽기 전용 상태
		- `:disabled`: 비활성 상태
		- `:enabled`: 활성 상태
		- ...
	- 요소 추가 선택자: `선택자::___`
		- `::before`: 자식의 첫번째 요소로 추가
		- `::after`: 자식의 마지막 요소로 추가
		- 반드시 추가할 내용이 있어야 노출 (content 정의 필수)
		- inline 속성
		- `::placeholder`: 가이드라인 텍스트
		- `::selection`: 선택된 영역

## CSS 속성

- 텍스트 및 텍스트 속성
	- `color`: 폰트 색상
		- `색상명`: red, blue, ...
		- `rgb(0~255, 0~255, 0~255)`: RGB 값으로 색상 조합
		- `16진수 표기` (hex code): `#ffccbb`
		- `rgba(0~255, 0~255, 0~255, 0~1)`: RGB값과 alpha 채널 추가,
			- 0에 가까우면 투명, 1에 가까울수록 불투명
	- `font-size`: 글자 크기
		- 절대 크기
			- `px`: 픽셀, 화소 기준
			- `pt`: 인쇄 기준
		- 상대 크기
			- `em`: 폰트 사이즈가 지정된 상위 태그
			- `rem`: root, 가장 상위 태그의 글자 사이즈 기준
				- html 태그에 설정된 px이 1rem

## CSS 박스 모델

- 박스 요소
	- Content
		- 기본 설정으로 너비와 높이의 기준 (width, height)
		- 내부 여백(padding)이나 경계선(border)를 지정하면 박스의 크기는 커진다.
	- Padding: 내부 여백, 경계선(Border) 안쪽
	- Border
	- Margin: 외부 여백, 경계선(Border) 바깥쪽
- box-sizing: 너비와 높이의 기준
	- content-box (기본값): 내용 영역(content) 기준
	- border-box: 경계선(border) 기준
		- 내부 여백(padding)이나 경계선(border) 두께 변경 시 내용 영역의 크기가 변경
- 외부 영역 (Margin)
	- block 속성 태그: 제한 없음
	- inline 속성 태그
		- 위, 아래 여백 적용 안됨
		- 좌, 우 여백 적용 가능
	- `margin: 상 우 하 좌;`
	- `margin: 상 좌우 하;`
	- `margin: 상하 좌우;`
	- `margin: 값;`: 모든 방향 동일
	- 특정 방향 한정하여 정의
		- `top`: 위
			- `margin-top: 50px;`
		- `right`: 우
		- `bottom`: 아래
		- `left`: 좌

## CSS Display

- Display
	- `block`: block이 아닌 속성을 block으로 변경
	- `inline`: inline이 아닌 속성을 inline으로 변경
	- `inline-block`: 줄개행하지않고 공간을 가져 너비, 높이를 설정가능, 여백 설정 가능
	- `none`: 감추기, 공간도 같이 사라짐
		- 참고) 
			- `visibility: visible`: (기본값)
			- `visibility: hidden`: 공간은 유지
- Flexbox: 1차원 정렬
	- 설정 - 부모 요소 (`display: flex;`)
	- 적용 - 자식 요소
	- `flex-direction`
		- `flex-direction: row;` (기본값) 좌 -> 우
		- `flex-direction: row-reverse;`: 우 -> 좌 
		- `flex-direction: column;`: 아래 -> 위
		- `flex-direction: column-reverse;`: 위 -> 아래
	- `justify-content`
		- `flex-start`: 왼쪽
		- `flex-end`: 오른쪽
		- `center`: 가운데
		- `space-between`: 좌우 요소 1개를 끝에 배치하고 나머지 요소들을 균등한 간격으로 배치한다.
		- `space-around`: 
		- `space-evenly`: 모두 동일한 공간으로 배치한다.
	- `align-items`: 자식요소들에 대한 위치, 배치
		- `stretch` (기본값): 부모 요소의 쿠기에 맞춰 늘림
		- `flex-start`: 위쪽 배치
		- `flex-end`: 아래쪽 배치
		- `center`: 가운데 배치

## 개인 학습장

RESTFull API Method 정리
- GET
	- 리소스를 조회할 때 사용
	- 데이터: 쿼리 스트링 사용
- POST
	- 새로운 리소스를 생성할 때 사용
	- 데이터: body 사용
- PUT
	- 리소스 전체를 교체(대체)할 떄 사용
	- 데이터: body 사용
- PATCH
	- 리소스 일부 필드를 교체(대체)할 때 사용
	- 데이터: body 사용
- DELETE
	- 리소스를 삭제할 때 사용
	- 데이터: body를 사용하는 경우도있지만 대부분 쿼리 스트링 사용
