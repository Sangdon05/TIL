## 양식 태그

- `<form>`: 양식 태그
	- `<input>`: 입력을 받기위한 태그
		- `action`: 제출 처리 URL
		- `target`
		- `method`: 전송 방식
			- `GET`(기본값): 자원조회, 검색 
				- 전송할 데이터는 URL에 포함
				- 값은 ?으로 시작, 값 구분은 & -> 쿼리 스트링 (Query String)
					- `url...?<key>=<value>&<key>=<value>`
			- `POST`
				- 서버에 변경을 가하는 요청 (회원가입, 글작성, 상품등록 등)
				- 요청 전문의 body에 실려 전송
				- url encoding
		- `type`: 입력 유형
			- `text`: 기본값
			- `password`: 비밀번호 마스킹 표시
			- `radio`: 여러개중 한개만 선택
			- `checkbox`: 여러개중 여러개 선택
			- `submit`: 양식 제출
			- `reset`: 입력 항목 초기화
			- `email`
			- `number`
			- `color`
			- `range`
			- `date`: 날짜
			- `time`: 시간
			- `datetime-local`: 날짜와 시간
			- `file`
		- `name`
			- 전송할 값의 이름
			- radio와 checkbox의 그룹 명칭
		- `value`
			- 입력값
			- `type`이 `text`, `password`, `name` -> 사용자가 입력 -> value로 할당
		- `checked`: `radio`, `checkbox` 등의 선택 설정
		- `required`: 필수 입력 항목
		- `min`
		- `max`
		- `step`
		- `placeholder`: 안내 문구
		- `readonly`: 읽기 전용 (데이터 전송이 된다.)
		- `disabled`: 기능 무력화 (데이터 전송이 안된다.)
	- `<button>`
		- `type`
			- `submit`: 양식 제출
			- `reset`: 양식 입력 취소
			- `button`: 일반 버튼
		- `<button ...>버튼명</button>`
	- 태그와 입력 요소 연결
		- 입력 요소를 태그로 감싼다.
			- `label` 태그를 주로 사용
		- `for`,`id` 속성을 연결시킨다.
	- `<textarea>`: 여러줄 텍스트 입력
	- `<select>`: 여러개중 한개 또는 여러개
		- `<option>`: 선택 항목
			- `selected`: 선택
		- `multiple`: 여러개 선택
		- `size`: 한번에 보일 갯수

## 시멘틱 태그 (Semantic Tag)
>의미를 가지고 있는 태그
>예) `<form>`, `<table>`, `<video>`, `<nav>` 등

- 필요한 이유
	- 검색엔진 최적화 (SEO)
	- 웹 접근성
	- 코드의 가독성
- 레이아웃을 구성하는 태그
	- `<header>`: 상단 공통 영역
	- `<footer>`: 하단 공통 영역	- `<main>`: 보문, 하나만 정의
	- `<section>`: 내용 본문
	- `<article>`: 세션별 내용
	- `<nav>`: 주 메뉴
	- `<aside>`: 왼쪽, 오른쪽 영역

## CSS (Cascading Style Sheet)
>웹 문서에 스타일링 담당

- 스타일 적용 기본 구조
	- 선택자 (selector)
		```
		선택자 {
			속성:값;
			속성:값;
		}
		```
	- 스타일 속성
		- `color`
		- `background`
		- `width`
		- `height`
		- ...
- 적용 방법
	- 인라인 스타일
		- 태그의 style 속성에 직접 적용
	- 내부 스타일 시트
		- `<style>...</style>`태그 안에 스타일을 정의 방법
	- 외부 스타일 시트 <- 가장 많이 사용하는 형태
		- css 파일을 생성하고 연동 (`<link ..>`)
- 주석: `/* ... */`
	- 설명
	- 해석 배제
- 선택자 (selector)
	- 전체 선택자 (`*`)
	- 태그 선택자 (`태그 이름`)
	- 클래스 선택자 (`.클래스명`)
		- 여러개 요소 선택, 복수개 선택가능, 여러개 이름 지정 
	- 아이디 선택자 (`#아이디명`)
		- 아이디 명은 하나만 지정 가능, 유일한 이름으로 지정
		- 1개만을 선택하는 속성
- 스타일 적용 우선 순위
	- 범위가 넓을 수록 순위가 낮아지고, 범위가 좁을 수록 높아진다.
	- 태그 선택자 < 클래스 선택자 < 아이디 선택자 < element style 속성
	- 태그 선택자 (공통 스타일), 클래스 선택자(세부 스타일)를 가장 많이 사용
	- 참고) 우선순위 강제 적용
		- `!important` -> 절대 남용 금지
- 복합 관계 선택자
	- 하위 선택자 (조상 - 자손)
	- 자식 선택자 (부모 > 자식): 바로위, 바로 아래 요소
	- 일반 형제 선택자 (형 ~ 동생): 기준 아래에 정의된 요소
	- 인접 형제 선택자 (형 + 동생): 기준 바로 아래 요소 1개
