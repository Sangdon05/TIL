## PostgreSQL

- 작은 따옴표(`''`): 문자열 리터럴
- 큰 따움표 (`""`): 구분 식별자, 컬럼, 테이블명 
	- 특수문자 포함
	- 대소문자를 섞어 쓰는 경우
	- 예약어

## SQL

DDL: 데이터 정의어
- 데이터 삭제 시 복구되지 않는다.
- CREATE: 생성
	- `CREATE [TABLE, INDEX, TYPE, ...]`
- DROP: 삭제
	- `DROP [TABLE, INDEX, TYPE, ...]`
- TRUNCATE: 데이터를 모두 비운다 (초기화)
	- `TRUNCATE TABLE <테이블명>`
- ALTER: 수정
	- 컬럼 추가
		- `ALTER TABLE <테이블명> ADD COLUMN <컬럼명> <자료형> [<제약조건>]`
	- 컬럼명 변경
		- `ALTER TABLE <테이블명> RENAME COLUMN <기존 컬럼명> TO <변경 컬럼명>`
	- 컬럼 삭제
		- `ALTER TABLE <테이블명> DROP COLUMN <컬럼명>`
	- 컬럼 자료형 변경
		- 데이터가 없을 경우
			- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> TYPE <자료형>`
		- 데이터가 존재하고 형변환이 필요한 경우
			- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> TYPE <자료형> USING (<컬럼명>::<자료형>)`
	- 컬럼 제약조건 추가/제거
		- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> SET [<제약조건명>]`
		- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> DROP [<제약조건명>]`
	- 컬럼 기본값 추가/제거
		- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> SET DEFAULT <기본값>`
		- `ALTER TABLE <테이블명> ALTER COLUMN <컬럼명> DROP DEFAULT`
	- 컬럼 제약조건 추가/제거
		- `ALTER TABLE <테이블명> ADD CONSTRAINT <제약조건 구분 이름> PRIMARY KEY(<컬럼명>, ...)`
		- `ALTER TABLE <테이블명> ADD CONSTRAINT <제약조건 구분 이름> UNIQUE(<컬럼명>, ...)`
		- `ALTER TABLE <테이블명> ADD CONSTRAINT <제약조건 구분 이름> CHECK(<조건식>)`
		- `ALTER TABLE <테이블명> ADD CONSTRAINT <제약조건 구분 이름> FOREIGN KEY(<현재 테이블 컬럼명>) REFERENCES <참조테이블>(<참조테이블 컬럼명>) [ON DELETE CASCADE|SET NULL]`
		- `ALTER TABLE <테이블명> DROP CONSTRAINT <제약조건 구분 이름>`

DML: 데이터 조작어
- INSERT: 추가
	- 하나 추가
		- `INSERT INTO <테이블명> [(<컬럼명>, ...)] VALUES (<값>, ...)`
			- 컬럼명 목록은 모든 컬럼이고 순서대로 추가하는 경우 생략가능
	- 여러개 추가
		- `INSERT INTO <테이블명> [(<컬럼명>, ...)] VALUES (<값>, ...), (<값>, ...), (<값>, ...)`
- UPDATE: 수정
	- `UPDATE <테이블명> SET <컬럼명>=<값>, ... [WHERE <조건식>]`
		- 조건식: 비교연산(>, <, =), 논리연산(AND, OR, NOT)
- DELETE: 삭제
	- `DELETE FROM <테이블명> [WHERE <조건식>]`


## 까마귀발 표기법

- `|` (수직선 하나): 최소 1개, 필수
- `O`(원): 0개 (선택적)
- `<`(까마귀발): 여러 개(N)
- `||`(수직선 두 개): 정확히 1개, 필수
- `O<`(원 + 까마귀발): 0개 이상
- `|<`(수직선 + 까마귀발): 1개 이상
