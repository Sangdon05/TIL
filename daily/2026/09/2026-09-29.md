## JavaScript

- 매개변수
	- 기본 매개변수
		- 기본 매개변수는 매개변수 끝에서부터 나열되어야한다.
	- `arguments` <- ES6 이전 사용하던 형태
		- 가변적 매개변수 개수가 필요할 시 사용
		- `for of`를 사용하여 매개변수 탐색
	- `...`: 나머지 매개변수 <- ES6+부터 이런 형태로 사용
		- 매개변수가 배열 형태로 입력된다.
		- 가변 매개변수, 나머지 매개변수, 전개 연산자 등으로 불린다.
		- 매개변수와 같이 사용 가능
			- `function 함수명(매개변수1, ...매개변수2)`: 매개변수2가 배열형태로 입력된다.
- 전개 연산자: `...`
	- 인수
		- `function 함수명(매개변수2, 매개변수2)`의 함수를 `함수명(...[인수1, 인수2])` 형태로 호출 가능
	- 배열 복사
		- `const 배열1 = [값, 값, 값];` 배열을 `const 배열2 = [...배열1];`로 복사 가능
		- `const 배열 3 = [...배열1, 값, 값];` 값을 추가 가능
	- 객체 복사
		- `const 객체1 = {키: 값, 키: 값};` 객체를 `const 객체2 = {...객체1};`
		- `const 객체3 = {...객체1, 키: 값, 키: 값};` 키와 값을 추가 가능
- 비구조 할당
	- 배열, 객체에서 원하는 값만 정의하여 변수로 할당 가능하다.
	- 배열
		- `const [변수1, 변수2, ...나머지] = 배열;`: 변수1, 변수2에 인덱스 0, 1값을 할당하고 나머지 값을 배열로 할당한다.
		- `const [변수1, , 변수3] = 배열;`: 배열에서 1번 인덱스를 제외하고 변수에 할당
	- 객체
		- `const {키1:변수1, 키2:변수2, ...나머지} = 객체`: 키1, 키2의 값을 번수1, 변수2에 할당되고 남은 키와 값은 나머지에 할당된다.
		- `const {키1, 키2} = 객체`: 할당할 변수이름이 키와 같다면 단축 가능
		- `const {키1, 키2: {키3}}`: 키2와 같이 중첩 객체일 경우 키3과 같이 할당 가능
- 일급 객체
	- 3대 속성
		- 변수 할당 (Assignment)
		- 매개변수 전달 (Argument Passing)
			- callback 함수
		    - 사용자 정의 함수
		    - 일회용 객체
		- 반환값 활용 (Return Value)
- 화살표 함수 (Arrow Function)
	- 정의 방법
		- `function` 키워드 생략
		- 매개변수 정의와 코드 실행 영역(`{}`) 사이에 `=>`로 표기
		- 코드 구현 부분이 함줄이면 `{}` 생략 가능, `return`도 생략 해야 한다.
		- 변수명도 한글자면 충분한다.
		- 매개변수가 1개면 `()` 생략 가능, 없거나 두개 이상이면 생략 불가
	- 제한 사항
		- 생성자 함수 사용 불가
		- arguments 객체 미지원
		- yield 사용 불가
	- `this` 바인딩
		- 일반 함수의 `this`: 함수가 호출되면 호출한 객체의 this를 참조
		- 화살표 함수의 `this`: 함수가 정의되는 시점에 이미 결정되어있는 this를 참조
- 고차 함수 (Higher Order Function)
	- 함수의 함수를 반환하는 함수
	- Factory 함수
	- 비동기 처리
- 명시적 this 바인딩
	- `apply`
	- `call`
	- `bind`
- 제너레이터 (Generator)
	- `*`과 `yield` 사용
	- ```js
	  function* 함수명() {
		  작업 1;
		  yield 작업 1 결과 반환;
		  작업 2;
		  yield 작업 2 결과 반환;
	  }
	  
	  const 객체 = 함수명();
	  객체.next(); // 작업 1 완료 후 결과 반환 받음 {value: 결과, done: false}
	  객체.next(); // 작업 1 완료 후 결과 반환 받음
	  객체.next(); // {value: undefined, done: true}
	  ```

## JavaScript 배열

- 배열 (Array)
	- 타 언어의 배열 정의
		- 같은 자료형 + 연속된 공간 구성
	- JavaScript의 배열 객체 (Array Object) 정의
		- 모든 타입의 값을 지정 가능
		- 여러개 관리 (데이터 군집): 컬렉션 중 하나
	- JavaScript의 배열 객체 특성
		- `Array` 생성자 함수로 생성
			- 1개이며 정수일때 0이상의 값으로 입력해야한다. 이 인자만큼 Array 길이를 생성하고 empty로 채워진다.
		- `Array.prototype` 상속 기준
		- `instanceof`: 객체의 상속관계 체크
			- 프로토타입 체인 관계
		- `[...]` == `new Array(...)`: 동일한 기능
		- 주요 메서드
			- 추가
				- `push(...)`: 요소를 뒤에 추가
				- `unshift(...)`: 요소를 앞에 추가
				- `splice(시작, 0, ...)`: 지정된 위치의 요소를 추가하거나 삭제
			- 삭제
				- `pop()`: 끝 요소를 꺼낸다. (꺼낸 값 반환)
				- `shift()`: 앞 요소를 꺼낸다. (거낸 값 반환)
				- `splice(시작, 삭제 갯수)`: 지정된 위치의 요소를 제거
			- 수정
				- `map(callback)`: callback 함수 정의 내용대로 변경
				- `filter(callback)`: callback 함수 정의 내용대로 필터링
			- 조회
				- `forEach(callback)`: callback 함수 정의 내용대로 순회
				- `indexOf(...)`: 요소의 위치 번호 (왼쪽 -> 오른쪽)
				- `lastIndexOf(...)`: 요소의 위치 번호 (오른쪽 -> 왼쪽)

## 데일리 퀘스트 오답 노트

배열 메서드 중 splice, push, pop처럼 원본 배열 자체를 직접 변경하는 메서드와 달리, slice, map, filter처럼 원본은 그대로 두고 새로운 배열이나 값을 반환하는 메서드를 통칭하는 용어(분류)를 쓰세요.

>교안에서는 배열 메서드를 원본을 직접 변경하는 '수정 메서드'와 원본은 유지한 채 가공된 값을 반환하는 '접근자 메서드'(및 반복 메서드)로 분류합니다. slice, concat, join 등이 대표적인 접근자 메서드입니다.
