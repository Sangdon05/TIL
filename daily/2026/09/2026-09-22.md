## JavaScript

- 증감 연산자
	- `++`: 1씩 증가
	- `--`: 1씩 감소
	- `let num2 = num1++;`: 대입 (1순위) -> `++` (2순위)
	- `let num2 = ++num1;`: `++` (1순위) -> 대입 (2순위)
- 일치 연산자
	- 동등성 비교: `==`
	- 동일성 비교: `===` <- 권장사항
	- 부정 연산: `!` (참은 거짓으로 거짓은 참으로 변환)
		- `!=`: 다르다
		- `!==`: 주소가 다르다.
- 논리 연산자
	- `&&`: AND 연산
	- `||`: OR 연산
	- `!`: NOT 연산 (부정 연산)
- 삼항 조건식
	- `변수 = 조건식 ? 참일때 : 거짓일때;`
- `??`: nullish 연산자
	- null 또는 undefined 일때만 판단
- `&&` 단락 회로 평가를 이용한 간단한 조건식 수행
	- `message && console.log(message);`
		- message가 정의되어있을 경우에만 log가 출력된다.
- 선택문 (`switch - case`)
	- `switch - case`: case 키워드에 매칭이되면 코드 실행 시점이고 break를 만날때까지 실행
		- `Fall-throught` (흘러내림)
			- break 문이 없을 경우 조건이 일치해서 들어간 case 이후의 모든 case 블록들이 조건 비교없이 아래로 연달아 실행되는 현상
	- `break`: 실행 흐름 중단
	- `default`: case에 매칭된 키워드가 없다면 마지막으로 유입되는 구간
- for 문 : 정해진 횟수만큼 반복하기
	- 순서의 의미가 강한 반복문, 관례적으로 변수명을 `i`로 사용
	    - `index`: 0부터 시작하는 순서를 의미
	- 여러 변수 선언 가능
		- ```js
			for (let i = 0, j = 10; i < 10; i++, j--) {
				console.log(`i=${i}, j=${j}`);
			}
		  ```

## JavaScript Naming 규칙

- 마침표(.) 연산자: 속성의 이름이 변수 이름 규칙에 해당하는 속성만 접근 가능
    - 변수명 규칙
        - 알파벳(대소문자), 숫자, _, $ 문자로만 구성
        - 숫자는 앞에 올수 없음
        - 예약어 (if, throw, ..)등은 사용 불가
    - 변수명 관례
        - 여러 단어로 구성된 변수가 있는 경우: camelCase 낙타 표기법
        - 여러 단어로 구성된 상수(변하지 않는 수)가 있는 경우: UPPER_SNAKE_CASE
    - 함수명 관례
        - 변수명 관례와 동일
        - 함수 중에서 생성자로 사용되는 함수는 앞글자를 대문자로 쓰는 것이 관례: PascalCase
- 대괄호(`[]`) 연산자: 변수명 규칙에 해당하지 않는 속성을 접근하는 경우
