## 플렉스 박스와 그리드 레이아웃

- `flex-grow`
	- 자식 요소 적용
	- <mark>남아있는 공백</mark>을 차지할 비율 설정
	- width가 0으로 설정한다면 전체 길이가 공백이 되기에 정확히 등분된다.
- `flex-shrink`
	- 부모 요소의 공간이 부족할때 자식의 크기 줄임 비율
	- 비율 가중치
	- `0`: 요소를 축소하지 않는다.
	- `flex-basis`: 요소의 기본사이즈
		- `auto`가 기본값
- `flex-wrap`
	- `wrap`: 부모 요소의 너비가 부족하면 다음칸에 개행
	- `nowrap` (기본값): 개행하지 않는다.

## CSS Grid (2차원 격자 레이아웃)

- `grid-template-columns`
	- `grid-template-columns: 150px 150px 300px`
		- 컬럼 3개 각각의 크기
	- `fr`: 남은 공간에 대한 비율
		- `grid-template-columns: 150px 1fr 2fr`
			- 첫번째 150px을 채우고 남은 공간에 두번째 1/3 세번째 2/3 크기로 배치
	- `repeat(컬럼수, 사이즈)`: 같은 사이즈의 지정된 컬럼개수만큼 설정
- `grid-template-rows`
- `gap`
	- `row-gap`: 행별 여백
	- `column-gap`: 열별 여백
	- `gap`
		- `gap 20px 10px`: `row-gap`, `column-gap` 순으로 입력
		- `gap 10px`: `row-gap` + `column-gap`
- `grid-column`
	- `grid-column: 1/3;`: 1번열 ~ 3번열까지 공간 배치
	- `gird-column span 2;`: 열의 2칸 차지
- `grid-row`
	- `grid-row: 1/3;`
	- `grid-rwo: span 2;`
- `place-items`
	- `stretch` (기본값)
	- `start`: 왼쪽 상단
	- `end`: 오른쪽 하단
	- `center`: 정가운데

## 폰트

- `color`: 글 색상 (생상명, RGB, hex code)
- `font-size`: 전체 크기, 상대 크기 (em, rem)
- `line-height`: 행간 (기본값 1.2 -> 1은 글자 높이, 20% 상단 하단 10% 할당)
	- 비율: 1.5 <- 권장사항
	- %: 150%
	- px, em, rem
- `letter-spacing`: 자간
- `word-spacing`: 단어 사이의 간격
- `word-break`: `wrap`, `nowrap`, `break-all`
- `font-weight`: 폰트 두께 
	- `normal` (기본값): 400
	- `bold`: 두껍게 700
	- `100 ~ 900`
		- 100에 가까울수록 가늘어지고, 900에 가까울수롱 두꺼워진다.
		- 폰트별로 지원하는 두께는 다르다. (확인 필요)
- `text-align`
	- 인라인 요소에 대한 정렬 (글 정렬은 글이 담긴 요소에 적용)
	- `left` (기본값): 왼쪽 정렬
	- `right`: 오른쪽 정렬
	- `center`: 가운데 정렬
	- `justify`: 양쪽 정렬
- `font-style`
	- `normal` (기본값): 스타일 없음
	- `italic`: 기울임체
	- `oblique`: 흘림체
		- `oblique 90deg;`: 각도 입력하여 기울지 조절 가능
- `text-decoration`
	- `underline`: 밑줄
	- `line-through`: 취소선 
	- `none`: 기본값
- `font-family`: 글꼴 설정
	- `font-family: 폰트명, 대체폰트1, "대체 폰트2", ...;`
		- 폰트명에 공백이 있으면 `""`로 감싸야한다.
	- 시스템 폰트: OS내에 설치되어있는 폰트
	- 웹 폰트: OS에 설치 상관없이 동일하게 공유 가능한 폰트

## CSS 속성

- `overflow`
	- `visible` (기본값): 넘치는 컨텐츠가 있어도 보이기
	- `hidden`: 넘치는 컨텐츠를 감추기
	- `scroll`: 넘치는 컨텐츠가 있으면 스크롤바를 표시한다.
	- `auto`: 넘치는 컨텐츠가 있으면 스크롤바가 표시되고 없다면 미노출
- `border`
	- `border-width`: 두께
	- `border-style`
		- `none` (기본값)
		- `solid`: 직선
		- `dashed`: 파선
		- `dotted`: 점선
		- `double`: 이중실선
	- `border-color`: 색상
	- 단축표현법
		- `border: 두께 스타일 색상;`
	- 방향성
		- `border-top`
		- `border-right`
		- `border-bottom`
		- `border-left`
	- `border-radius`: 모서리를 둥글게 그린다.
- `background`: 배경
	- `background-color`: 배경색
	- `background-image`: 배경 이미지
		- `url("이미지 경로")`
	- `background-repeat`: 
		- `repeat` (기본값): x, y 축 모두 반복
		- `repeat-x`: x축 반복
		- `repeat-y`: y축 반복
		- `no-repeat`: 하나만 출력
	- `background-position`: 배경 이미지 위치 설정
		- `background-position: 100px 50px`: 좌에서 우로 100px, 위에서 아래로 50px
	- `background-size`
		- `background-size: 200px 100px;` 가로, 세로 순으로 입력
			- 강제 크기 조절으로인해 이미지가 외곡될수있다. 가로 기준으로만 선언하는 방법으로 사용할수있다. (`background-size: 100%`)
		- `cover`: 영역을 모두 채운다. 이미지의 비율이 배경요소와 다를 경우 일부 이미지는 짤린다.
		- `contain`: 이미지가 모두 보일수 있도록 채운다.
	- `background-attachment`
		- `fixed`: 스크롤 시 배경이미지 고정
		- `scroll`: 스크롤 시 배경이미지도 같이 스크롤된다.
	- 단축 표기법
		- `background: (색상 or 이미지) [반복 고정 위치 사이즈]`
			- 색상과 이미지 둘다 사용가능, 둘 중하나는 꼭 사용해야한다.

## CSS Positioning

- `position`: 위치 (배치)
	- 절대 위치
		- `static` (기본값): 요소의 위치 고정
	- 상대 위치
		- `relative`
			- 속성이 정의되어있는 요소
		- `absolute`
			- 문서 전체 기준
			- 부모 요소가 상대속성(`relative`, `absolute`, `fixed`)이면 부모가 기준점
		- `fixed`
			- viewport 기준 (보이는 기준)
		- 층위 설정 가능
			- `z-index`: 값이 높을수록 앞쪽 배치, 값이 낮을수록 뒷쪽 배치
