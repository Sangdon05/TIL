## DOM (Document Object Model)

- 브라우져에서 사이트 렌더링 절차
	- 입력한 주소로 html 텍스트 요청
	- Document 객체 변환
	- 트리 구조 구축 (DOM Tree)
	- DOMContentLoaded 이벤트 발생
	- Load 이벤트 발생
		- 자원로드 완료
- 호스트 객체
	- 런타임마다 다르게 구성되어있는 특화 객체
		- 웹브라우저 객체
			- 브라우저 기능과 밀접하게 관련
		- window
			- location 객체: 웹브라우저 주소창과 관련된 정보, 기능 제공
				- `assign(주소)`: 지정된 주소로 이동
					- `location.href`: 속성을 변경하면 동일하게 동작
				- `replace(주소)`: 지정된 주소로 이동하지만 히스토리를 남기지 않는다.
				- `reload()`: 새로고침
				- 속성: 실시간성 -> 변경 내용이 실제 반영 (주소창에 변화가 반영됨)
					- `hash`: 해당 id로 이동 -> `주소?#id`
			- history 객체: 방문기록과 관련된 정보, 기능 제공
				- `length`: 방문 기록 갯수
				- `scrollRestoration`: 스크롤 위치 기억 옵션
					- `auto`: 스크롤 위치를 자동으로 기억하여 뒤로가기로 이 페이지로 진입 시 이전 위치 복구
					- `manual`: 스크롤 위치를 복구하지 않음
				- `back()`: 한단계 뒤로가기
				- `forward()`: 한단계 앞으로 가기
				- `go(숫자)`: 숫자만큼 앞/뒤로 이동 (숫자가 음수이면 뒤로, 양수이면 앞)
			- screen 객체: 브라우저 사용화면 정보, 기능 제공
			- navigator 객체: 브라우저 OS 사용환경, 기타 API 정보, 기능 제공
			- document 객체: HTML 문서와 관련된 정보, 기능 제공
			- ...
- Document 객체
	- DOM Tree: 빠른 요소 탐색을 위해 필요
	- 요소(DOM)을 선택하는 방법
		- `id`로 선택: 1개만 선택
			- `document.getElementById(아이디명);`
		- `class`로 선택: 복수개 선택
			- `document.getElementsByClassName(클래스명);`
		- 태그 이름으로 선택: 복수개 선택
			- `document.getElementsByTagName(태그명);`
		- `name`으로 선택: 복수개 선택
			- `document.getElementsByName(속성명);`
		- CSS 선택자로 선택
			- `document.querySelector(CSS 선택자);`: 첫번째 요소 1개만 선택
			- `document.querySelectorAll(CSS 선택자);`: 복수개 선택
		- 문서 전체 (html): `window.document`
			- `head`: `window.document.head`
			- `body`: `window.document.body`
		- 양식(form) 이름
			- 양식 하위 입력 태그는 이름으로 바로 접근 가능
				- `form-name.id`
		- 요소 노드 (상대적 접근)
			- `parentElement`: 부모 요소
			- `children`: 자식 요소
			- `firstElementChild`: 첫번째 자식 요소
			- `lastElementChild`: 마지막 자식 요소
			- `nextElementSibling`: 다음 형제 요소
			- `previousElementSibling`: 이전 형제 요소
	- 요소의 추가 정보
		- 속성 (Attribute)
			- `document.getAttribute(속성명);`: 속성 조회
			- `document.setAttribute(속성명, 속성값);`: 속성 추가/변경
			- `document.removeAttribute(속성명);`: 속성 제거
			- `document.hasAttribute(속성명);`: 속성 존재 여부
			- 많이 쓰는 속성은 바로 접근 가능
				- `id`, `type`, `src`, `href`, `target`, `action`, `className`, `style`, ...
		- 데이터 속성
			- `document.dataset`: 객체
				- `document.dataset[키] = 값;`으로 설정 가능
				- `data-키` 형식으로 속성으로 추가된다.
		- 클래스 속성
			- `document.classList`: 클래스 추가, 삭제, 조회 가능
				- `contains`: 존재 유무

## 데일리 오답노트

```
외부 자바스크립트 파일을 <script> 태그로 불러올 때 사용하는 속성 중, HTML 파싱을 막지 않고 병렬로 다운로드하지만 실행 시점에는 파싱이 중단되며 여러 파일 간 실행 순서가 보장되지 않는 속성은 무엇인가요?

async 속성은 다운로드는 비동기로 진행하지만 다운로드가 끝나는 즉시 실행되며 이때 파싱이 중단되고 실행 순서도 보장되지 않습니다. defer는 실행이 DOM 트리 구축 완료 시점으로 예약되고 순서가 유지되므로 오답입니다. loading과 sync는 교안에 존재하지 않는 속성명입니다.
```
