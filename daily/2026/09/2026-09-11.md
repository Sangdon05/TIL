## Python

파이썬의 타입 힌트
- `변수: 타입`: 
	- `num: int = 100`
	- `title: str = "타이틀"`
	- `list: list = []`
- `def 함수(...) -> 타입:`: 반환 타입
	- `void`: 반환값이 없는 경우, 생략 가능

데이터 클래스: `@dataclass`
```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    description: str
    price: int = 0
```

```python
@dataclass(kw_only=True) # 키워드 매개변수만 사용
class Product:
    name: str
    price: int = 0
    description: str
```

	- `SELECT`구문내에서 사용가능
	- 매개변수와 반환값

	- `CALL <프로시저명>(...);`
	- 독립 프로그램
	- **트랜잭션 제어 가능**
		- `COMMIT`, `ROLLBACK` 정의 가능
- 트리거 (Trigger)

security definer
- 정의된 함수에서만 INSERT 등의 행위를 할수있도록 정의
