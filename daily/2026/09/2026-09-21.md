## JavaScript

- 인터프리터 언어
- 자바스크립트 해석 엔진
	- 웹브라우저(크롬) - V8
	- `Node.js` - V8
- `nvm` 설치: Node Version Manager
	- `node`: 자바스크립트 코드를 실행 runtime
	- `npm`: Node Package Manager
		- 외부 패키지를 설치할 때 사용하는 명령어
			- `http://npmjs.com`
		- `node.js` 프로젝트 생성, 실행
	- `npx`: Node Package Executor
		- 패키지의 명령어를 실행
- Jupyter 설정
	- `uv tool install --with jupyter jupyter-core`
	- `npm i -g tslab`
	- `uv run --with jupyter npx tslab install`
- 호이스팅: 정의한 변수, 함수가 최상위 객체에 할당되는 현상
	- 함수 정의 위치에 상관없이 호출 가능
- `var`
	- 호이스팅 문제
	- 변수의 유효범위(scope) => 함수
		- 전역변수 오염 문제
	- 선언자(`var`)를 생략하고 변수를 지역변수로 정의하면 전역 변수가 된다.
- 모던 JavaScript -> 2015년 기준 
	- ES6 - ECMA Script 6
		- ECMA: 유럽 표준 단체
	- `let`, `const`
		- 유효범위 - block level
		- 호이스팅 해결
		- 중복 정의 불가
		- `let`: 값 변경이 가능
		- `const`: 값 변경 불가능
	- <mark>자바스크립트에서는 변수를 선언할때 const로 선언하고 변경이 필요한 경우만 let으로 변경</mark>
- 데이터 타입
	- Number (숫자형): 정수와 실수를 따로 구분하지 않고 모든 숫자 형식
	- String (문자열): `''`, `""`로 감싼 텍스트
	- Boolean (불리언): `true`, `false`
	- null: 값이 없는(비어 있는) 상태임을 표시
	- undefined: 정의되지 않음, 변수를 선언한 후 값을 대입하지 않으면 기본값
- 연산자 오버로드
	- `+`, `-`, `/`, `*`, ...
		- 연산자의 기능을 새롭게 정의
	- `+`: 자료형에 따라 다르게 동작

		- `stream`

ipynb에서 상위 폴더의 .py 파일을 import 해야할 경우 아래와 같이 사용

```python
import sys
import os

# 현재 노트북 파일의 상위 폴더 경로를 구하여 sys.path에 추가합니다.
parent_dir = os.path.abspath(os.path.join(os.getcwd(), '..'))
if parent_dir not in sys.path:
    sys.path.append(parent_dir)
```
