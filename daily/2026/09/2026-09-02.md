## 데이터베이스 (DBMS)

데이터란?
- 데이터: 처리되지 않은 값 (원시값, raw data)
	- 이름, 나이, 구매금액 등
- 정보: 데이터에 의미를 부여

DBMS (Database Management System)
- 데이터를 관리하는 소프트웨어
- RDBMS: Relation Database Manage System
	- 테이블 간의 관계 명시 (관계형 데이터베이스)
		- MySQL / MariaDB
		- Oracle
		- MSSQL
		- PostgreSQL
			- 확장기능 - VectorDB -> RAG 활용

SQL (Structured Query Language)
- Query: 데이터베이스에 보내는 질문, 질의 -> 작성 규칙 (SQL)

관계형 데이터베이스
- 테이블(Table): 데이터를 저장하기 위한 공간
	- 행과 열로 구성된 2차원 구조
	- 행: Row, Record
	- 열: Column, Field, 속성
	- 셀: 각각의 데이터 (주문 번호, 주문 상품, ...)
- 스키마 (Scheme)
	- 테이블의 구조와 제약사항을 정의한 명세서

DBMS 사용 목적
- 데이터 무결성 제약조건을 위해 사용
	- 도메인 무결성 제약조건
		- 동일한 컬럼은 동일한 자료형을 사용해야한다.
	- 개체 무결성 제약조건 (기본키 제약조건)
	- 참조 무결성 제약조건
- 자료형 (Data Type)
	- 숫자형
		- 정수
			- SMALLINT (2byte)
			- INT (4byte)
			- BIGINT (8byte)
		- 실수
			- REAL (4byte)
			- DOUBLE PRECISION (8byte)
			- DECIMAL (P: 전체 자리수, S: 소수점 자리수)
	- 문자형
		- CHAR(자리수): 고정 자리수의 문자
		- VARCHAR(최대 자리수): 최대 자리수 만큼의 문자, 최대를 넘지 않으면 문자 크기만큼만 공간을 할당한다.
		- TEXT: 여러줄의 텍스트 (길이 제한이 없는 가변 문자열)
	- 논리형
		- BOOLEAN (1byte)
			- TRUE, FALSE, NULL
	- 날짜와 시간
		- DATE: 날짜
		- TIME: 시간
		- TIMESTAMP: 날짜 + 시간
		- TIMESPAMPZ: 날짜 + 시간 + 시간대 (기본적으로 UTC+0)
	- JSON
		- JSONB: 바이너리로 저장된다. -> 권장, 속도가 빠르다.
		- JSON
	- 기타
		- ENUM: 열거형
		- VECTOR: 차원수

기본키 (Primary Key)
- 하나의 레코드를 식별할수 있는 대표 컬럼 또는 컬럼의 조합
- 중복 허용되지 않음 - 유일한 값
- 값이 반드시 있어야한다. - Not Null

## 데일리 퀘스트 오답 노트

디코더 전용 모델이 문장을 생성할 때, 현재 시점보다 미래에 위치한 단어를 참조하지 못하도록 어텐션 스코어의 상삼각 영역을 차단하는 기법의 이름은 무엇입니까?

> 인과적 마스킹(Causal Masking)은 어텐션 스코어 행렬의 상삼각 영역을 마스킹하여 모델이 역방향(미래 시점) 정보를 참조하지 못하게 하는 기법으로, Gemma와 같은 디코더 전용 모델의 인과적 텍스트 생성을 가능하게 합니다.
