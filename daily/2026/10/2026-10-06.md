## TypeScript

- 유니온 타입
	- 여러 타입 중 하나를 선택적으로 선언
- 인터섹션 타입
	- 복수 객체 타입을 하나로 합성
	- extends를 주로 사용한다.
- 리터럴 타입
	- 허용 값을 제한하는 타입으로 모델링
	- enum 대신 주로 사용한다.
		- enum 타입은 이점이 적어 잘 사용하지 않는다.
- 타입 가드
	- `typeof`
	- `in`
	- `instantof`
- 서로소 판별 유니온
	- 판별자
		- 객체 타입을 구분하는 공통 속성
	- `switch`문을 활용한 상태 분기
- 제네릭 (Generic)
	- 함수, 클래스의 타입을 인자로 전달하여 매개변수와 반환값의 타이을 동적으로 정한다.
- 제네릭 인터페이스
	- 객체 구조를 정의할 때 특정 속성의 타입을 유동적으로 바꿀수 있는 재사용 가능한 규격
- 제네릭 제약 조건 
	- `extends`
	- `keyof`
- 클래스 접근 제한자
	- `public`
		- 클래스 내부, 외부 모두 접근 가능
	- `protected`
		- 클래스 내부에서만 접근 가능
		- 상속을 통해 하위 클래스 내부에서 접근 가능
	- `private`
		- 클래스 내부에서만 접근 가능
	- 생성자 단축 속성 선언
- 추상 클래스
	- 추상: 사전적 의미
		- 공통적인 / 일반적인
		- 정해지지 않은
	- 함수의 기능 수행이 정의되지 않은 클래스
	- 클래스 키워드 앞에 `abstract` 키워드 추가
- 인터페이스
	- 객체 구조를 정의하는 타입
	- 메서드는 모두 추상 메서드
	- 객체의 설계만을 위한 타입
