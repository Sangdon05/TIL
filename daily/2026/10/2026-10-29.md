## 파일 업로드

- `form`: `enctype=multipart/form-data`
- `input`: `type=file`

## 정적 파일 연결

- `app.mount`에 주소를 지정하여 `StaticFiles`로 설정
- `url_for`
	- 파일 경로를 하듴딩하면 주소 변경 시 문제 발생
	- 역방향 주소 분석으로 접속 주소를 동적으로 생성하여 해결

## Router

- `prefix`: 라우터 안의 모든 API 주소 앞에 공통으로 붙을 시작 주소
- tags: API 문서에서의 그룹화
- `dependencies`
	- 특정 라우터 그룹 전체에 공통 규칙을 정용하고 싶을때 사용
	- 한번 등록하면 하위 모든 API에 자동 적용
- FastAPI 객체의 `include_router()`를 통해 등록

## 미들웨어

- API 요청 처리 전, 후의 작업을 정의하여 실행한다.
- CORS (Cross Origin Resource Sharing)
	- 기본 정책: 같은 출처 접근 허용
	- 같은 출처 판단
		- 동일 서버, 프로토콜, 도메인 주소, 포트 번호
		- 이외에는 다른 출처로 판단하여 접근 거부
- 클라이언트(브라우저 등)에서 서버로 요청할때 1차 Options(preflight) 형식으로 가능 여부를 확인하고 실제 요청을 진행한다.
- `TrustedHostMiddleware`
	- 허용된 주소로 들어오는 요청만 통과
- 밀들웨어는 마지막에 등록된 것부터 실행된다.
