## Next.js

- React.js와 차이점
	- React.js
		- 라이브러리
		- build
			- index.html, css, js ...
		- CSR (Client Side Rendering)
		- 장점
			- 인터넷 연결이 없어도 화면 출력
			- 화면 전환이 빠르다.
		- 단점
			- 약간의 초기 로딩 지연
			- SEO 문제 (검색 반영되지 않음)
	- Next.js
		- 프레임워크 (React.js 기반)
		- SSR (Server Side Rendering)
			- prerender: 서버에서 번역해서 내용이 있는 html 전송
			- hydration: html에 동적 자바스크립트 특성 반영
- 배포방식
	- React.js
		- jsx, tsx => Babel (트랜스파일러) => js
		- 번들링(webpack)으로 배포가능한 상태로 빌드
	- Next.js
		- 트랜스파일, 번들링 성능을 높이기위해 Rust로 개발
		- SWC (Speedy Web Compiler), Turbo


- export
	- 모듈 내보내기
	- 다른 파일에서 사용할수 있다.
- import
	- 모듈 가져오기
	- `import { 모듈명, ... } from 모듈 경로;`


- JSX (JavaScript XML)
	- 단일 태그 -> 반드시 끝맺음 기호 필수
	- 소괄호 `(...)`에 JSX 객체 정의
	- 변화감지 효율성을 높이기 위해서 컴포넌트는 단일 노드로 구성해야한다.
		- 여러 노드를 한 컴포넌트에 정의 해야한다면, 출력하지 않는 단일 컴포넌트(`<Fragment>` 혹은 `<>`)로 감싼다. 
	- JSX 문법 구간 안에서 자바 스크립트 코드를 사용하는 경우 중괄호(`{}`)로 작성
	- 조건식
		- 삼항조건
		- `&&` 연산 (단락 회로 평가)
	- 주석
		- `{/* ... */}`
		- `{// ..` 줄개행 후 중괄호 닫기 필요
	- React.JSX.Element
		- JSX 요소만 반환
	- React.ReactNode
		- JSX 요소, 다른 형태의 값(문자, 숫자, null, 함수, ..)
- TSX (TypeScript XML)
