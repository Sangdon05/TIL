Memory Swap 설정
- 프리티어에서는 메모리 1기가 제공. 메모리 스왑 설정으로 디스크에 메모리 스왑이 가능하도록 설정

```bash
sudo dd if=/dev/zero of=/swapfile bs=128M count=32
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
sudo swapon -s
```

서버가 재구동 되면 스왑 설정은 활성화 되지 않습니다. 서버가 재구동 되도 스왑 설정이 유지 되도록 다음 설정을 추가 합니다.
```bash
sudo vi /etc/fstab  (파일열고)
/swapfile swap swap defaults 0 0  (를 끝 줄에 추가)
```

자동 실행 설정
```bash
sudo vi /etc/systemd/system/shoppingmall.service
```

```
[Unit]
Description=Shopping Mall Next.js Service
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/app

# nvm의 node 및 npm 경로를 PATH에 우선 등록
Environment="PATH=/home/ubuntu/.nvm/versions/node/v24.22.1/bin:/usr/local/bin:/usr/bin:/bin"
Environment=NODE_ENV=production

# 환경 변수 파일 로
EnvironmentFile=/home/ubuntu/app/.env.production

# 올바른 npm 바이너리 경로 지정
ExecStart=/home/ubuntu/.nvm/versions/node/v24.22.1/bin/npm run start

# 프로세스 비정상 종료 시 재시작 설정
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
