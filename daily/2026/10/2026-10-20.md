- useRouter
	- next/router: SSR
	- next/navigation: CSR
		- window.location과 비슷한 기능
		- CSR로 동작
			- 화면 이동 없이 화면 교체
		- `push(이동경로)`: 방문기록을 남기는 이동
		- `replace(이동경로)`: 방문기록을 남기지 않는 이동
		- `refresh()`: 새로고침
- `useEffect(콜백함수, [])`: 비동기로 동작
	- 시점별 실행되는 훅
	- 컴포넌트별 렌더링 완료 후 설정된 함수 호출
	- 화면 재렌더링 하지않고 값 변화만 감지
	- 기능 정의
		- 원격데이터 조회
		- DOM 선택
		- Native Event Binding
	- 인수 정의
		- 의존성 - 배열
			- 빈배열 - 컴포넌트 렌더링 후 1번 호출
			- 의존성이 변경되면 재호출
- useInsertionEffect: 동기로 동작
	- DOM 변경 후 레이아웃 계산 전 호출
- useLayoutEffect: 동기로 동작
	- 레이아웃 계산 직후 (렌더링 전)
- `revalidatePath(경로, 'layout' | 'page')`: 케쉬 삭제
	- 경로, 테그 단위로 캐쉬 저장
	- layout: 전체
	- page: 페이지
- `useSearchParams()`: CSR 기준의 쿼리스트링 값
