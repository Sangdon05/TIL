Request <---> Response
- 무상태성 (stateless)

요청 전문
- 해더 (header)
	- 요청 방식
		- GET: 자원 조회
		- POST: 서버의 자원을 변경하는 요청
		- DELETE: 삭제
		- PUT: 전체 치환
		- PATCH: 부분 치환
	- 요청 데이터 형식
	- 사용자 요청 정보, 브라우저 언어, 브라우저 종류
- 바디 (body)
	- 서버로 전송할 데이터
	- 전송 데이터 형식 명시
		- Content-Type
			- application/x-www-form-urlencoded
				- 이름=값&이름=값: 16진수로 인코딩되어있음
			- application/json
				- {"이름":"값", ...}
- Options
	- 모든 요청 전에 먼저 요청
	- 요청 메서드, 자원 허용 설정 확인
	- CORS 오류
		- Cross Origin Resource Sharing
		- 같은 출처가 아니면 자원 공유하지 않음 (기본)
			- 같은 프로토콜, 도메인, 포트
- HAD: 응답 헤더 조회

응답 전문
- 헤더 (header)
	- 응답 다비의 형식 (Content-Type)
	- 서버의 정보
	- 서버가 브라우저에게 요청하는 행동
		- Location: 주소 -> 페이지 이동
		- Set-Cookie: 쿠키 등록
- 바디 (body)
	- 서버에서 보내주는 내용
- 응답 코드
	- 2xx
		- 200: 정상 처리
		- 201: 장성됨 (POST)
	- 3xx
		- 301: 영구 이동 (응답 헤더에서 Location: 주소)
		- 302: 임시 이동
		- 304: 캐시됨
	- 4xx: 클라이언트 오류 (사용자의 실수인 경우가 많다.)
		- 400 
			- 잘못된 형식 요청 (Bad Request)
			- 유효성 검사 실패
		- 401: 인증 권한 없음 (Unauthorized)
		- 403
			- 자원 접근 권한 없음 (Forbidden)
			- 관리자 페이지 접근 (권한 부족)
		- 404: 페이지 없음
	- 5xx: 서버 오류
		- 500
			- 서버 내부 오류 (Internal Server Error)
			- 코드 상의 오류인 경우가 많다.
		- 502: Bad Gateway
		- 503: Service Unavailable
