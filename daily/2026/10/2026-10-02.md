#typescript

## TypeScript

- TypeScript
	- ES5 < ESNext < TypeScript 
		- 상위 호환성
		- Superset
	- 정적타입
	- 일반 언어의 특징 도입 (Java, C#, ...)
	- TypeScript 문법 -> TSC -> Javascript 변환 -> 실행
- 자료형
	- `string`, `number`, `boolean`
	- `null`, `undefined`
	- `array`
	- `tuple`
	- `any`, `unknown`
		- 타입을 명시하기가 어려운 특수한 상황
		- `any`
			- 컴파일 시 타입체크를 하지 않는다.
			- 모든 타입 가능
			- 타입오류를 체크하지 않기에 런타임에서 오류 가능성 높다.
			- <mark>사용 지양</mark>
		- `unknown`
			- 모든 타입 가능
			- 로직 상에서 타입을 알수있는 코드 반드시 필요, 하지 않을 시 커파일 시 오류 발생
				- `typeof`, `instanceof`
			- `any`보다는 타입 안정성이 있다.
	- never
		- 값을 반환하지 않음을 명시
		- 값을 반환한다면 오류로 인식
- 함수 타입 표현식
	- `(매개변수: 타입, ...) => 반환값 타입`
- 인라인 함수 시그니쳐
	- `{(매개변수: 타입, ..): 반환값 타입}`
