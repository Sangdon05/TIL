	- URI (Uniform Resource Identifier)
- 표현적 상태 전이

## 도메인 모델

- 도메인
	- 전문가 영역
	- <mark>비지니스 요구사항</mark>
		- 개발자가 해결해야할 문제 영역
- 도베인 모델
	- 비지니스 요구사항을 담은 설계도
	- 데이터 + 행위
	- 변수, 함수, 용어 -> 비지니스 영역의 용어와 일치 시킨다.

## HTTP

- `Body(...)`
	- 요청 바디 데이터 
	- post, put, patch
	- 기본 Content Type: `application/json`
- `Form(...)`
	- 일반 양식
	- 기본 Content Type: `application/x-www-from-urlencoded`
- `Query(...)`
	- 쿼리스트링 값

## curl

- `-H`: 보내는 데이터의 형태 설정 (Content Type)
- `-d`: 서버에 보낼 데이터
- `-X`: GET, POST, PUT, DELETE 등 요청 메서드
- `-i`: 반환 상태 코드와 http 해더 정보 표시

## 4 Layered Architecture

- application: 응용
- domain: 도메인
