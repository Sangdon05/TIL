## Event

- 이벤트: 웹페이지 내에서 발생하는 모든 사용자의 
- 이벤트 핸들러: 이벤트가 발생했을 때 시랭되는 함수
- 쓰레드: 작업자, 작업 단위
	- call stack
	- 실행 영역 함수
- 멀티 쓰레드: 여러개의 쓰레드로 동시 작업
- `setTimeout(이벤트 핸들러, 지연시간);`
	- 지연시간은 밀리세컨드
	- 지연시간에 이벤트 핸들러 실행
- `clearTimeout(핸들러 등록 번호);`
	- 취소
- `setInterval(이벤트 핸들러, 지연시간);`
	- 반복 지연 실행
	- 지연 시간 만큼 만복해서 이벤트 핸들러 실행
- `clearInterval(핸들러 등록 번호);`
	- 취소

## 이벤트 등록 방법

- HTML 요소의 이벤트 속성
	- 1개만 등록 가능
		- 다른 이벤트 핸들러를 등록 -> 변경 -> 1개까지만 등록 가능
- `documnt.addEventListener(이벤트명, 이벤트 핸들러, 캡쳐링 여부=false);`
	- 캡쳐링 여부
		- `false`: 버블링 단계에서 전파
		- `true`: 캡처링 단계에서 전파
- 이벤트 전파
	- 캡처링 단계 -> 타겟 단계 -> 이벤트 핸들러가 실행 -> 버블링 단계 (타겟 단계의 이벤트가 상위 요소로 전파)
- 이벤트 객체
	- 이벤트 핸들러의 첫번째 매개변수
		- 발생한 이벤트와 관련된 정보
	- 이벤트 통제 메서드
		- `stopPropagation()`: 이벤트 전파 차단
		- `stopImmediatePropagation()`: 이벤트 전파 차단, 같은 요소의 다른 이벤트도 차단
		- `preventDefault()`: 기본 동작 차단 (예: a 태그의 이동 기본 동작)
	- 요소 접근
		- `이벤트 객체.currentTarget`: this와 동일한 대상 참조, 이벤트가 바인딩된 요소
		- `이벤트 객체.target`: 실제 이벤트가 발생한 요소
		- `this`: 이벤트가 바인딩된 요소

## 이벤트 종류

- 마우스 이벤트

	- `mouseup`: 마우스 버튼을 땔때 발생
	- ...
	- `scroll`
- 키보드 이벤트
	- `keydown`: 키를 눌렀을때 발생
	- `keypress`: 기능키 (alt, ctrl 등)에는 동작하지 않음
	- `keyup`
	- ...
- 마우스 포인트 위치 정보
	- 뷰포트 기준
		- clientX

	- ...
