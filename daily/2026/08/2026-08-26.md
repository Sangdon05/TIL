# 머신 러닝

선형 회귀: 1차 방정식
$$\hat{y}=wx + b$$ 
- 가중치 (weight) 
- 편향 (bias)
- $w$, $b$: 모델 파라메터 -> 모델이 학습을 통해서 결장된 값

미분
- Loss 판단: 기울기가 0에 가까워질수로 Loss가 적다

검증 - 모델 평가
- 예측을 잘하면 오차(Error)가 작다.
- Loss (손실): 오차의 대표값
	- 모든 오차를 더한다. (음수, 양수 값으로 존재하기에 상쇄가 된다.) <- 사용되지 않는다.
	- Loss Function (손실 함수): 대표값을 구하는 공식
		- MSE (Mean Squared Error): 평균 제곱 오차 
		  $$MES = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $$
			- 곡선: 미분가능 (최적의 가중치를 결정 가능)
			- 이상치에 민감
		- MAE (Mean Absolute Error): 평균 절대값 오차 
		  $$MAS = \frac{1}{n} \sum_{i=1}^{n}|y_i - \hat{y}_i|$$
			- 미분이 어렵다.
			- 직관적인 크기 확인 가능
		  

학습 과정
- 손실(Loss)를 확인하고 가중치 조절 (가중치, 편향) 반복
- Loss를 최대한 줄여서 예측의 정확도를 높여야한다.
- 학습의 목적은 Loss 값의 최저로 갈수있는 최적의 가중치, 편향을 결정하는 것
- 경사 하강법
- 가중치 업데이트 공식: **옵티마이저**
	- 역전파 (Back Propagation) -> 가중치의 업데이트 정도 $$w_{new} = w_{old} - \alpha(\frac{\partial J}{\partial w})$$
	- 기울기 (Gradient) $$\frac{\partial J}{\partial w}$$
	- $J$ : 비용 함수 / 손실 함수
	- $a$: Learning Rate (학습률)
		- 점진적으로 가중치를 조정하기 위한 값
		- 모델을 개발하는 개발자가 설정하는 값 -> 하이퍼 파라메터
		- 정답은 없으며 실험을 통해서 설정한다.
		- Overshooting
		- Undershooting

옵티마이저
- SGD: 확률적 경사 하강법
- Momentum: 관성(방향, 속도)
- RMSProp: 학습률 조정해서 학습의 효율성 높임
	- Adaptive 계열
- Adam(Adaptive Momentum Estimation)
	- Momentum + Adaptive 특징
	- 가장 많이 사용
