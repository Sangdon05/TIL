# Class와 Instance

객체(Object)의 정의
- 속성: 변수
- 행위: 함수, 메서드

객체 지향 프로그래밍 (OOP)
- 객체간의 상호작용의 개념

Class: 객체를 만들기 위한 설계도
- 클래스 정의 시 힙 영역에 PyObject -> PyCodeObject -> Class 명세 등록
- 클래스로 인스턴스 생성 시 힙 영역에 Class 객체 생성, Call Stack에서는 힙 영역에 생성된 Class 객체 참조
- 생성자(`__init__`)
- 메서드의 self 키워드 매개변수
- `__str__`, `__repr__`
	- `__str__`: print를 객체의 참조변수를 출력하려면 자동으로 호출되는 메서드
	    - 보통 객체 내에 있는 인스턴스 변수의 내용을 출력하는 경우가 많다.
	- `__repr__`: print를 하면 자동으로 호출(`__str__`과 비슷), `__str__` 우선 순위가 높다.
	    - 로깅 목적(기록을 위한 목적, 디버깅): 클래스명(매개변수=값, ..) -> eval() 문자열을 실행했을때 객체가 만들어지는 형태로 정의
	    - repr(객체 참조변수): 문자열로 반환해준다.

객체(Object)와 인스턴스(Instance)의 차이
- 객체: 클래스로 구현할 대상 전체를 아우르는 포괄적인 개념
- 인스턴스: 클래스를 바탕으로 메모리(Heap 영역)에 실제로 할당되어 고유한 상태를 가진 구체적인 실체

# 상속과 캡슐화

- `isinstance(참조변수, 클래스/자료형)`: 자료형 확인
- `super()`로 부모 객체 method 접근 가능
- 정보 은닉 `__변수명`: 외부에서 인스턴스 변수로 접근하여 값을 변경할수 없도록 한다.
- getter, setter: 정보 은닉 후 외부에서 변경하거나 가져올수 있도록 한다.
- 정보 은닉과 getter, setter는 입력값 통제를 위한 수단
