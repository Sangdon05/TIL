LEGB 스코프 개념  -> 접근 우선 순위 : 좁은 범위가 우선순위가 높다.
- L: 지역 변수(Local)
- E: 외부 함수 변수(Enclosing)
- G: 전역 변수(Global)
- B: 내장 함수(Built-in)

전역 변수를 사용하고자 할떄 `global` 키워드 사용 - 사용 주의: 전역 변수에 의도치 않는 변경을 주어 사이드 이펙트 발생 가능
```
a = "Global"

def outer():
    a = "Enclosing"

    print("outer: ", a)

    def inner():
        global a # a라는 변수는 전역 변수를 찾는다.
        print("inner: ", a)

    inner()

outer()
```

일급 함수 (First-class Function)
- 함수의 매개변수로 함수를 사용할 수 있다. -> 콜백 함수
- 함수의 반환값으로 함수를 사용할 수 있다. -> 팩토리 함수
	- 참조되는 변수들을 PyCellObject로 힙 영역에 추가된다. 
- 사용자 정의 함수

고차 함수 (Higher-order Function)
- 클로져(Closure)
- 내부 함수에서 참조하는 지역 변수는 Heap에서 관리되므로 외부 함수가 종료되더라도 사용가능하다.

익명 함수 (lambda)
- 간단하게 일회용으로 사용하는 경우 한줄의 식으로 간단하게 함수 정의

데코레이터 (Decorator)
- Wrapper
- 공통 작업을 일괄적으로 적용할수 있어 효율적이다.
- 디자인 패턴 중 하나

재귀함수 (Recursive)
- call stack에 재귀한 횟수만큼 쌓이기 때문에 메모리 관리에 신경 써야한다.
