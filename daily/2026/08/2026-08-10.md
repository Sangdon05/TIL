## 자료구조
`collection`

CRUD
- C -> Create : 추가
- R -> Read : 검색
- U -> Update : 수정
- D -> Delete : 삭제

### 1. 순차 자료구조
순서가 있는 자료

`str`, `List`, `Tuple` : `[1, 2]`, `(1, 2)`

- 인덱스 연산자 사용법 학습
- 자료형의 주요 기능 학습
- 패킹, 언패킹 학습
- 자료형의 얕은 복사, 깊은 복사
### 2. 집합 자료구조
- 중복 허용하지 않음
- 순서 중요하지 않음

`set` : `set([1, 2])`

- 합집합: `|` `union()`
- 교집합: `&` `innersection`
- 차집합: `-` `difference`
- 대칭 차집합: `^` `symmetric_difference`
### 3. 사전 자료구조
- key, value 쌍으로 구성
- key는 고유값이다.

`dictionary` : `{"key": "value"}`
