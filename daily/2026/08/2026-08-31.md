## 과적합 해결방법
드롭아웃 기법 (Dropout): 학습 중 일정 비율의 뉴런 출력을 랜덤하게 0으로 비활성화
- 특정 뉴런에 과도하게 의존하는 동시 적응(Co-adaptation)을 방지하여 다른 뉴런들도 고르게 학습(가중치 분산)되도록 유도한다.

## 신경망 학습 4단계 순환 구조
순전파 (Feed Forward) -> 손실 계산 (Loss Evaluation) -> 역전파 (Back Propagation) -> 옵티마이저 가중치 갱신 (Weight Update) 순서로 에포크(Epoch)만큼 반복

> **출력층 활성화 함수와 손실 함수 (Logits vs Activation)**
> 손실 함수(CrossEntropyLoss 등)와의 결합 시 수치적 안정성(Numerical Stability)을 위해 모델 출력층에서는 Softmax를 생략하고 **로짓(Logits)**을 직접 출력하여 손실 함수 내부에서 계산하도록 구성하는 방식을 주로 사용한다.

# RNN (Recurrent Neural Network)
1. 시계열(순차) 데이터에 특화
2. 이전 스텝의 정보를 다음 스텝으로 전달하며 순서를 기억
3. 문장 (자연어) - 어순과 맥락에 따라 의미 완성

### 단어 표현 방식
- **One-Hot Encoding**
  - 단어를 고차원 희소 벡터로 표현
  - 단어 간의 유의미한 유사도나 의미적 관계를 파악하지 못함
  - 단어 수가 많아질수록 차원이 커져 비효율적
- **임베딩 (Embedding)**
  - 지정된 저차원 공간에 연속적인 실수 값으로 압축 (밀집 벡터, Dense Vector)
  - 단어와 단어 사이의 유의미한 관계 및 유사도를 표현 가능
  - 임베딩 가중치 행렬 ($W_{\text{emb}}$)을 통한 룩업(Lookup) 연산:
    $$\text{Embedding}(w) = \text{One-Hot}(w) \times W_{\text{emb}} = v$$

### RNN 셀과 동작 구조
- 하나의 셀(Cell)을 타임스텝마다 가중치를 공유하며 재사용
- **셀 (Cell)**: 이전 정보를 기억하고 처리하는 기본 단위
- **타임스텝 (Time Step)**: 순차적 데이터의 시간/순서별 처리 단계
  - **은닉 상태 갱신 수식**:
    $$h_{t} = \tanh(W_{h}h_{t-1} + W_{x}x_{t} + b)$$
    - $h_t$: 현재 시점의 은닉 상태(Hidden State) / 맥락(Context Vector)
    - $h_{t-1}$: 이전 시점의 은닉 상태
    - $x_t$: 현재 시점의 입력 벡터
    - $W_h, W_x, b$: 모든 타임스텝에서 공유되는 가중치 및 편향 파라미터
- **활성화 함수**:
  - **ReLU**: RNN에서는 타임스텝을 거치며 값이 계속 누적·증폭되어 폭발(Exploding Gradient)하기 쉬워 기본 바닐라 RNN에서는 잘 쓰이지 않음.
  - **하이퍼볼릭 탄젠트 ($\tanh$)**: 출력 범위가 $-1 \sim 1$로 제한되어 값의 급격한 발산을 억제함.
    - **한계점**: 타임스텝이 길어질수록 기울기가 $0$에 수렴하는 **기울기 소실(Gradient Vanishing)** 발생 $\rightarrow$ 먼 과거의 정보를 잊어버리는 **장기 의존성(Long-Term Dependency) 문제**.

### LSTM (Long Short-Term Memory)
- RNN의 장기 의존성 문제를 해결하기 위해 등장한 구조
- **단기 기억 (Short-Term Memory)**: 은닉 상태 ($h_t$)
- **장기 기억 (Long-Term Memory)**: 셀 상태 ($C_t$, Cell State)
- 게이트(Gate) 메커니즘(망각, 입력, 출력 게이트)을 통해 정보를 얼마나 유지하고 버릴지 조절
