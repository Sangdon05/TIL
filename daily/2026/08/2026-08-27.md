# 머신 러닝

다중 회귀
- 특성 갯수만큼 가중치가 추가된다.
- 수치가 커지면 더 큰 영향력을 가진다.
- 기준을 통일해야한다. - 정규화
	- MinMaxScaler: 최소, 최대값을 이용
		- 0 ~ 1 사이의 값으로 압축 
		- $X_{new} = \frac{X - 최소값}{최대값 - 최소값}$
	- StandardScaler(Z-Score) : 표준 점수 <- **자주 사용한다.**
		- 평균을 0으로하고 표준편차를 1로 조정
		- $X_{new} = \frac{X - 평균}{표준 편차}$
- 분산 
  $$\sigma^2 = \frac{1}{n}\sum_{i=1}^{N}(X_{i}-\mu)^2$$
	- $\sigma^2$ (시그마 제곱):  분산
	- $X_i$: 각 데이터의 값
	- $\mu$: 데이터의 전체 평균
	- $N$: 전체 데이터의 개수
- 표준편차
  $$\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{N}(X_{i} - \mu)^2}$$
	- $\sigma$ (시그마): 표준편차
		- 분산에 루트($\sqrt{ }$)를 씌워 제곱된 단위를 원래대로 되돌린다.

다중 회귀 규제(Regularization) 
- L1 규제 (라쏘 Lasso)
	- $$Loss = MSE + \alpha \sum_{j=1}^{P}|w_j|$$
		- $P$: 모델에 사용된 독립 변수(Feature)의 총 개수
		- $\alpha$: 규제 강도, 적절한 규제 강도를 실험을 통해 적합한 강도를 찾아야한다. -> hyperparameter
	- 영향력이 적은 특성의 가중치를 0으로 치환
- L2 규제 (릿지 Ridge) <- **가장 많이 사용하는 규제**
	- $$Loss =MSE + \alpha \sum_{j=1}^{P}w_{j}^2$$
		- $P$: 모델에 사용된 독립 변수(Feature)의 총 개수
		- $\alpha$: 규제 강도, 적절한 규제 강도를 실험을 통해 적합한 강도를 찾아야한다. -> hyperparameter
	- 영향력이 큰 가중치에 벌점(Loss)을 크게 높인다.
	- 영향력이 작은 가중치는 벌점(Loss)을 갖게 높인다.
	- 가중치가 0에 아주 가까워질 뿐 완전한 0이 되지 않는다.

특성 공학 (Feature Engineering)
- 특성들을 조합해서 새로운 특성을 추가해 주는 전처리 기법
- 특성의 개수를 너무 늘리면 과적합이 될수있다. 적절하게 늘리는게 중요하다.

학습 데이터 **분할**
- 학습 세트 (Train Set)
	- 모델이 학습하는 데이터
- 검증 세트 (Validation Set)
	- 학습 주기(Epoch/Batch)마다 모델을 평가하기 위한 데이터
	- 평가 -> Loss -> 가중치 조정 (역전파, 옵티마이저)
- 테스트 세트 (Test Set)
	- 모델이 학습을 완료하고 모델의 성능을 평가하기 위한 데이터
- 통상적으로 학습 셋트 60%, 검증 세트 20%, 테스트 세트 20%로 사용하지만 상황에 따라 다르게 설정하여 사용한다.

학습은 적절한 횟수로 시켜야 좋다.
- Loss가 떨어지지 않을때 학습 종료 (Early Stopping)
- 과적합 (Overfitting)
	- 학습을 더 진행 불필요한 상황
	- 학습을 진행할수록 Loss가 높아진다.
- 과소 적합 (Underfitting)
	- 학습이 덜된 상황

다중공선성 (Multicollinearity)
- 원소 변수들끼리 서로 지나치게 밀접한 상관관계를 가져서 독립적인 기여도를 파악하기 어려워지는 중복 간섭 현상
- 데이터가 아주 조금만 바뀌어도 중요도 평가가 널뛰어 모델의 신뢰도가 크게 추락
- 새로운 데이터를 마주했을 때 예측력 상실
