## 자료형

명시적 형변환 (Explicit Type Conversion)
- int(): 정수형으로 변환
- float(): 실수형으로 변환
- str(): 문자형으로 변환
- bool(): 논리형으로 변환

묵시적 형변환 (Implicit Type Conversion)
- Upcasting

형변환 시 주의해야 할 예외와 에러 (ValueError)
- "20"이라는 문자는 숫자로 변환 가능하지만, "20세"라는 문자는 숫자로 변환할수없기 때문에 ValueError를 발생시킨다.

## 연산자

연산자 종류
- 대입
- 복합 대입
	- 이항 연산을 단항으로 변경
	- `a = a + 1` -> `a += 1`
- 부호 반전
	- 음수 <-> 양수
- 산술
- 비교
- 논리
	- `and`, `or`, `not`

연산자 우선순위
- 강제 우선순위 지정 `()` > 산술 > 비교 > 논리 > 대입

단락 회로 평가
- 논리 연산 시 결과가 확정되었다면 이후의 항들은 평가(실행)하지 않는다.

# 문자열

- 1세대: % 연산자
- 2세대: str.format() 메서드
- 3세대: f-string

정렬 및 서식 지정 지시자
- 1세대
	- `%{숫자}s`: 최소 숫자 자리수 만큼 공간 차지, 남는 공간은 공백
	- `%{숫자}d`: 최소 숫자 자리수 만큼 공간 차지, 남는 공간은 공백
	- `%{대체문자}{숫자}d`: 최소 숫자 자리수 만큼 공간 차지, 남는 공간은 대체문자로 체워짐
	- `%.{숫자}f`: 소숫점 아래로 숫자만큼 표시한다.
	- `%{숫자}.{숫자}f`: 최소 숫자 자리수 만큼 공간 차지, 남은 공간은 공백, 소숫점 아래로 숫자만큼 표시한다.
	- `%{대체문자}{숫자}.{숫자}f`: 최소 숫자 자리수 만큼 공간 차지, 남은 공간은 대체문자로 채워짐, 소숫점 아래로 숫자만큼 표시한다.
- 2, 3세대 공통
	-  `:`, `:>`, `:<`, `,`
- 3세대
	- 디버깅 조절자 `=`
