메모리
- 정적 메모리
	- 코드 영역
		- 내장함수
		- 제어문
	- 전역 변수
- 동적 메모리
	- Heap 영역
		- PyFunctionObject
		- PyCodeObject
		- 함수의 매개변수 정의
		- 수행 코드 정의
	- Stack 영역
		- 함수 실행 영역 메모리 (임시 메모리)
		- PyFrameObject

변수
- 전역 변수
	- 함수 외부에 정의된 변수
- 지역 변수
	- 함수 내부에 정의된 변수

인수
- 위치 인수
- 키워드 인수
- 관례: 필수 값 -> 위치 인수, 옵셔널 값 -> 키워드 인수
- 키워드 인수는 오른쪽 끝부터 차례대로 정의해야한다.

매개변수
- 가변 인수
- 키워드 가변 인수
- 위치 인수가 필요할 경우 위치 인수가 먼저 와야한다.

자료 구조
- Stack
	- last in first out
- Queue
	- first in first out
