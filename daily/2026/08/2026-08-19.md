클래스 변수와 인스턴스 변수
- 클래스 변수(정적 변수)
- 인스턴스에서 접근하는 것이 아닌 `클래스명.변수`로 접근 권장

`@classmethod`와 `@staticmethod`
- 객체를 생성하지 않아도 접근 할 수있다.
- `@classmethod`에서는 첫번째 인자로 클래스 객체를 참조할수있는 변수를 할당해야한다.

```python
class Calculator:
    count = 0

    # clz -> Calculator 클래스 객체 참조 변수
    # clz -> 클래스 변수, 다른 클래스 메서드를 접근하기 위한 목적
    @classmethod
    def add(clz, num1, num2):
        clz.count += 1
        print("호출 횟수: ", clz.count)
        return num1 + num2

    @staticmethod
    def minus(num1, num2):
        return num1 - num2
```

예외처리
- 구문 오류(Syntax Error)와 런타임 예외(Exception)
- 서비스가 중간에 중단되지 않게 하기위해 런타임 예외 처리 중요
- `try - except - else - finally`
- traceback -> 서비스 중 오류 발생 시 디버깅을 위한 자료 수집
	- traceback.print_exc(): 에러 스택 콘솔 출력
	- traceback.format_exc(): 에러 스택을 문자열로 변환
	- traceback.print_stack(): 에러 없이 현재 호출 흐름 확인
- raise -> 직접 예외 발생 시키기
- 사용자가 직접 예외를 정의하여 관리할수있다.
	- Exception을 상속 받거나 Exception을 상속받고있는 예외를 상속받아서 사용

디버깅
- Breakpoint
	- Continue
		- 다음 Breakpoint로 이동
	- Step Over
		- 지금 줄을 실행하고 다음줄로 이동한다. 함수가 있더라도 함수 내부로 들어가지 않고 결과 값만 받는다.
	- Step Into
		- 현재 줄에 함수가 있다면 함수로 이동하여 안착, 함수의 상세 동작 확인 시 사용
	- Step Out
		- 현재 실행중인 함수에서 남은 코드를 모두 실행 후 함수를 호출했던 상위 흐름 위치로 복귀
