# 프롬프트 기법

Few-shot Prompting
- 예시를 들어 원하는 형태로 답변 받을때 사용

Role Prompting
- 특정 직업, 페르소나, 전문가의 정체성 지정
- 유사도 기반으로 토큰 생성

Zero-shot CoT (Chain-of-Thought)
- 추론 절차를 요청하여 복잡한 계산이나 논리적 문제 해결 능력을 올린다.

Few-shot CoT (Chain-of-Thought)
- 추론 절차 예시 추가

Step-Back Prompting
- 상위 원리나 기본 개념을 먼저 정리하게 한 후 본 문제를 풀게하는 기법

> 1. 사용자 질의
> 2. 질의에서 필요한 배경지식 도출 질문
> 3. 배경지식 도출
> 4. 다시 Step-Back Prompting 기법을 이용하여 질문하여 최종 질문을 받는다.

프롬프트 5대 요소 - RTCCF
- Role: 전문가의 페르소나와 출력 확률 분포 재구성
- Task: 핵심 임무 하달과 어텐션 메커니즘 집중
	- 행동 동사
	- 체인 프롬프팅
- Context: 배경 지식 제공을 통한 컨텍스트 엔지니어링
	- 맥락 기반 결과물 조정
- Constrains: 탈선 방지를 위한 가드레일 및 네거티브 프롬프팅
	- 네거티브 프롬프팅 -> 하지말아야 할것을 명확히 지정
- Format: 데이터의 구조화 및 출력 그릇의 설계

예제
- domain/prompt/RTCCF-실습예제
- domain/prompt/Lovable-웹페이지-실습-예제

## Numpy

배열(Array)
- 메모리상 동일한 자료형으로 연속된 구조
- 1차원: Vector
- 2차원: Matrix
- 3차원 이상: Tensor

차원 변경
- `reshape(행, 열)`: 1차원 배열을 지정된 행과 열 구조로 변경
- `arange(시작, 종료, 증감)`: 시작 이상 종료 미만으로 숫자 생성
- `flatten`: 2차원 배열을 1차원 배열로 평탄화
## Pandas

Series와 DataFrame
- Series: 1차원 구조체
- DataFrame: 2차원 표 형태의 구조체

탐색적 데이터 분석 (EDA)
- `df.info()`
    - 누락치 확인 (Non-Null Count)
    - `dtype`: 통계가 가능한 자료형인지 확인 (잘못된 데이터 여부 확인 -> 치환 -> 자료형 변환)
- `df.describe()`
    - 평균, 중앙값, 최대, 최소값을 통해서 이상치(극단치)를 확인

브로드캐스팅 연산
- 기본 연산자(+, 등 산술 연산자)
    - DataFrame, Series 연산 시 열 이름 기준으로 브로드캐스팅 연산 수행
- 산술 메서드(`.sum(), .sub()`, `.div()` 등)
    - axis=0(행 인덱스 기준) 또는 axis=1(열 기준)을 명시하여 정밀하게 브로드캐스팅한다.
