적응적 학습률 (RMSProp)
- 옵티마이저 중 하나
- 가중치가 자주 변경 -> 학습률 하락 => 미세하게 가중치 변경
- 가중치가 거의 변경되지 않음 -> 학습률 높음 => 가중치 크게 변경

로지스틱 회귀 (Logistic Regression)
- 회귀 방식을 이용한 분류 모델
- Logits(로짓): 선형 결합의 결과값 ($z = w_1x_1 + w_2x_2 + b$)
- 활성화 함수 (Activation Function): Logits 값을 0 ~ 1 사이의 확률값으로 변환
- logits
	- 100% 확률로 거의 나올 수는 없다. -> 적정 확률 임계값(Threshold)을 설정한다.
	- 양성 클래스, 음성 클래스

이진 분류 (Binary Classification)
- 활성화 함수: 시그모이드 (Sigmoid) (0 ~ 1)
	- $\frac{1}{1+e^{-z}}$
	- $z$값이 커질수록 1에 수렴한다.
	- $z$값이 작아질수록 0에 수렴한다.
- 손실 함수 (Loss Function): BCE (Binary Cross Entropy)
	- $Loss = -(y\log(\hat{y}) + (1 - y)\log(1-\hat{y}))$
		- $\log(1)$: 0
		- $\log(0) \to -\infty$ (예측이 완전히 틀렸을 때 Loss $\to \infty$)
		- $\hat{y}$: 예측값 (0 ~ 1)
		- $y$: 실제값 (0 또는 1)
		- $y$가 1이고 $\hat{y}$가 0일 경우 분류를 틀렸다. -> 벌점이 높게
		- $y$가 1이고 $\hat{y}$가 1일 경우 분류를 맞췄다. -> 벌점이 낮게

다중 분류 (Multiclass Classification)
- 활성화 함수: 소프트맥스 (Softmax)
	- $\frac{e^{z_i}}{\sum_{j=1}^{C}e^{z_j}}$
	- 전체 1에서 각 클래스별 확률 출력
- 손실 함수: 
	- CCE (Categorical Cross Entropy)
		- $Loss = -\sum_{c=1}^{C}y_{c}\log(\hat{y}_{c})$
			- 정답이면 벌점을 적게
			- 정답이 아니면 벌점을 높게
		- One-Hot Encoding
			- 다중 분류의 경우 숫자로 레이블링할 경우 숫자의 크기를 중요도로 오해할 수 있다. -> Vector로 표현
			- 문제점
				- 분류 개수(클래스)가 많아지면 희소 벡터가 되어 메모리 소비가 많아진다.
				- 연산량도 많아진다.
	- SCCE (Sparse Categorical Cross Entropy)
		- $Loss = -\log(\hat{y}_{target})$
			- $target$: 정답 클래스의 인덱스
		- 정수형 레이블을 그대로 사용하며 내부적으로 해당 인덱스의 확률값으로 손실을 계산한다.
	- Embedding Vector
		- 고차원 희소 벡터를 저차원의 연속적인 실수 밀집 벡터(Dense Vector)로 변환

K-Fold 교차 검증 (K-Fold Cross Validation)
- 데이터를 K개의 폴드(Fold)로 나누어, K-1개로 학습하고 1개로 검증을 K번 반복 수행하여 모델의 일반화 성능을 평가

다층 퍼셉트론: DNN (Deep Neural Network)
- 입력층과 출력층 사이에 은닉층(Hidden Layer)을 추가한다.
- 입력층 -> 은닉층
	- $z_{1} = w_{1}x_{1} + b_{1}$
- 은닉층 -> 출력층
	- $z_{2} = w_{2}z_{1} + b_{2}$
- 입력층 -> 은닉층 -> 출력층 (활성화 함수가 없을 경우)
	- $z_{2} = w_{2}(w_{1}x_{1} + b_{1}) + b_{2} = w_{2}w_{1}x_{1} + w_{2}b_{1} + b_{2} = w_{new}x_{1} + b_{new}$
		- 합성 가중치: $w_{new} = w_{2}w_{1}$
		- 합성 절편: $b_{new} = w_{2}b_{1} + b_{2}$
		- 활성화 함수가 없으면 여러 층을 쌓아도 단일 선형 모델과 동일해짐
- 은닉층에 추가되는 활성화 함수
	- 선형적인 특성을 비선형적으로 변환
	- 시그모이드(Sigmoid) 함수: 0 ~ 1 사이로 압축 -> 기울기 소실(Gradient Vanishing) 문제 발생으로 깊은 신경망 학습이 어려움
	- ReLU 함수: $\max(0, z)$ -> 음수는 0, 양수는 그대로 통과하여 기울기 소실 완화
