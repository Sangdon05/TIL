Iterable과 Iterator
- `__iter__`
- `__next__`
- 반복 가능 객체로 정의한다. (`next(...)`)

Generator
- `yield`
- 함수 실행을 중지하고 원할 때 재개 할수있다. (`next(...)`)
- 재개 할 때마다 힙 영역에 해당 값을 할당한다.
- 코루틴(Coroutine)
- Generator 표현식
	- 리스트 컴프리헨션과 동일한 형태이지만 리스트 대신 튜플로 감싸서 표현한다.

동기(sync)와 비동기(async)
- 동기: 순서대로 실행하고 결과도 순서대로 도출
- 비동기: 순서대로 작업을 시작하지만 결과는 먼저 처리된 순서대로 도출
	- 적은 리소스로 효율적인 작업이 가능하다.

모듈/패키지
- 모듈 (Module) -> python 파일
- 페키지 (Package) -> python 파일들이 모아져있는 폴더
- `import <모듈명, ...>`
- `import *`: 모듈 내의 모든 자료 선언
- `from <모듈/패키지명>`
- `as <별칭>`: 모듈, 변수 등의 별칭 지정
- 패키지 상대 경로 표현: 
	- `..`: 상위 패키지. 더 상위를 올라가게 된다면 `....`으로 표현 (`..` 당 한 단계 상위)
	- `.`: 현재 패키지
- `__name__`: 모듈명
	- terminal에서 직접 python 실행 시 `__name__`은 `__main__`으로 표시된다.
- `__init__.py`: 현재 디랙토리가 패키지임을 알려주는 파일. 강제는 아니지만 호환을 위해 생성 권장
