내장 함수 학습 권장
- 기본 제공하는 함수가 직접 구현하는 것보다 성능, 안정성이 검증되어있다.

인스턴스가 생성될 때 `__init__`보다 `__new__`가 먼저 호출된다.

내장 함수
- enumerate(_iterable_, _start_: int): start 값부터 시작하여 (index, item) 형식 iterator를 생성한다.
- sorted(_iterable_): 정렬된 새로운 리스트를 반환한다.
- `min()`, `max()`: 숫자만이 아닌 배열에서 오른차순 변경 후 첫요소, 마지막 요소로 최소/최대를 반한할수 있다.

표준 라이브러리
- random
	- shuffle(_sequence_): 배열내 요소들을 임의의 순서로 변경한다.
	- `randint(a, b)`: a 이상 b 이하
- json
	- 다른 플렛폼간의 소통을 위한 표준 데이터 형식
	- javascript 객체를 정의하는 형식을 빌려온 것

파일 입/출력 (I/O)
- 입력 (Input)
	- 데이터 읽기
- 출력(Output)
	- 데이터 쓰기
- close() 하지 않는다면 메모리에 계속 남아있게된다.
	- 닫히면서 buffer에 담겨 있는 내용을 모두 파일에 적용하고 비운다.
- 파일 포인터 (fp)

with 구문
- `__enter__`: 첫 라인에서 호출
- `__exit__`: 마지막 라인 실행 후 호출

```python
class MyResource:
    def __init__(self):
        print("__init__")

    def __enter__(self):
        print("__enter__ 호출")
        return self

    # with 구문이 종료되었을 때 또는 예외가 발생했을떄 호출
    # 예외가 발생 시
    #   exc_type - 예외 클래스 종료
    #   exc_val - 예외 메시지
    #   exc_tb - tranceback 메시지
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("__exit__ 호출")
```

```python
with MyResource() as o: # __enter__ 호출
    print(o)

    # 종료 시 __exit__ 호출
```
