# Pandas

loc와 iloc를 활용한 행·열 선택
- `loc`: 인덱스 연산자(`[]`)로 행의 이름으로 검색(선택)
    - `loc[행 라벨]`
    - `loc[행 라벨, 컬럼 이름]`
    - `loc[시작행:종료행, [컬럼1, 컬럼2, ...]]`
    - `loc[..., 시작 컬럼:종료 컬럼]`
- `iloc`: 인덱스 연산자(`[]`)로 숫자 인덱스로 검색(선택)
    - loc와 사용방법은 동일하지만 헬 라벨이 아니라 인덱스 번호로 조회
    - 범위를 설정할 경우 종료 번호는 미만
    - `iloc[0:2, 0:2]` -> 인덱스 0, 1, 컬럼 0, 1

불리언 인덱싱
- 컬럼별 값이 True인 조건만 찾아서 조회
- `&`: and 연산 / 모두 참일때 참
- `|`: or 연산 / 조건 중 하나만 참이여도 참

query 필터링
- 문자열 조건식(`and`, `or`) 및 `@`표시로 외부 변수 참조 활용

결측치(Missing Data) 7대 처리 기법
- 결측치 탐지 및 현황 요약 (Detection)
- 결측치 삭제 (Drop)
- 통계적 대푯값 대치 (Imputation)
- 시계열 직전/직후 값 대치 (Forward / Backward Fill)
- 선형 보간법 (Linear Interpolation)
- 이상 기호 치환 및 수치형 변환 (Replace & Type Casting)
- 결측 여부 지표 변수 생성 (Missing Indicator)

그룹화 집계(groupby)
- `groupby()`

# Matplotlib

캔버스(Figure)와 축(Axes) 기본 구조 (fig, ax)
- 산점도: 데티어의 분포
	- `scatter()`
- 꺾은선 그래프: 시계열 데이터의 흐름
	- `plot()`
- 막대 그래프: 시계열 데이터의 흐름
	- `bar()`
- 히스토그램: 데이터의 빈도수
	- `hist()`
		- bins: 빈도 구간
- 박스플롯: 이상치의 분포
	- `boxplot()`
- 캔버스 생성
    - `feature(figsize=())`: 1개를 그릴때
    - `subplots(행, 열, figsize=())`: 여러개를 그릴때
- `figsize=()`: 캔버스의 크기 (가로인치, 세로인치)
