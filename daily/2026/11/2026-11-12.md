## RAG
> Retrieval Augmented Generation

- LLM의 한게
	- 지식 Cutoff 존재
		- 학습된 시점의 지식으로 고정으로 이후 지식은 없다.
	- 지식의 부재로 인한 환각 발생
		- 특정 도메인의 지식도 없을수 있다.
- 외부 지식 저장소 (Vector DB)
	- 사용자 질의를 받으면 관련성 있는 배경 지식 탐색을 위해 외부 지식 저장소를 검색한다.
	- 프롬프트 증강 (Augmented)
	- 청크 단위로 지식 적제 (Chunk)
		- ETL(Extract Transform Load) 과정을 통한 적제
			- Extract
				- text, pdf, html
			- Transform
				- 데이터 전처리
				- 청킹
				- 임베딩
			- Load
				- DB 적제
- 의미 검색
	- 유사도 계산을 위한 임베딩 모델을 통해 수치로 변경
	- 유사도 계산 기법
		- <mark>유클리디언 거리</mark> (수치가 작을수록 유사)
		- <mark>코사인 유사도</mark> (1에 가까울 수록 유사. -1에 가까울 수록 반대의미)
		- <mark>내적의 차이</mark> (방향과 크기)
- 키워드 유사성 검색
	- BM25 (Best Matching) 검색 알고리즘
- 하이브리드 검색
	- 의미 검색과 키워드 유사성 검색을 같이 사용
- 청킹 (Chunking)
	- 너무 긴 텍스트
		- 컨텍스트 윈도우 크기의 한계
		- 의미적 유의성 저하
		- LLM 답변 품질 저하
	- 최적의 청킹 사이즈는 품질 평가를 통해서 조정
- 프롬프트 엔지니어링
	- Rewrite Query 기법
		- LLM을 통해 검색에 적합한 질문으로 변환
	- Reranking
		- LLM을 통해 결과에 점수를 매겨 순위를 다시 정리한다.

## 교안 학습

- RAG 5단계 흐름
	- 수집, 분할, 임베딩, 검색, 생성을 거처 사실 기반의 답변 완성
	- 인덱싱 파이프라인
		- 문서 수집
		- 문서 분할
		- 임베딩 및 저장
	- 질의 파이프라인
		- 검색
		- 생성
- 단계별 주요 병목 현상 및 영향
	- 수집 단계 결함
		- 표가 깨져있거나 글자가 누락된 상태
		- 모든 후속 단계가 잘못된 데이터를 다루게됨
	- 분할 단계 결함
		- 문맥 고려가 되지 않은 청킹으로 의미 파악 불가
	- 임베딩 단계 결함
		- 단어의 의미적 유사성 계산이 잘못되어 엉뚱한 거리 값 도출
	- 검색 단계 결함
		- 관련 없는 청크가 전달되어 모델이 잘못된 참고
	- 생성 단계 결함
		- 주어진 무서를 무시하고 지어내는 환각 현상
