## RAG 평가셋 (Evaluation Set)

- 표준 평가지 (Golden Set)
	- 질문 (Question): 사용자가 실제로 입력할 법한 자연어 질의
	- 모범 정답 (Ground Truth / Answer): 해당 짊ㄴ에 대해 시스템이 최종적을 답변해야 하는 올바른 기준 텍스트
	- 근거 문서 (Context): 검색기가 본문 데이터베이스에서 반드시 찾아내야 하는 원본 문서 청크
- 검색 단계 평자 지표
	- 검색 지표 (Retrieval Metrics)
		- 정답 문서를 빠짐없이 가져왔는지, 불필요한 노이즈를 섞어 가져오지 않았는지 정략화한 수치
- 정밀도 (Context Precision)
	- 검색기가 반환한 문서들 중 실제 정답 근거 문서가 차지하는 비율
	- 검색 결과의 순도(Quality)를 나타냄
- 재현율 (Context Recall)
	- 전체 데이터베이스에 존재하는 정답 근거 문서 중 검색기가 누락 없이 찾아낸 비율
	- 검색의 포괄 범위(Coverage)
- 조화 평균 (F1-Score)
	- 정밀도와 재현율의 트레이드오프(Trade-off)
		- 검색 범위를 넓히면 정답을 놓치지 않지만 무관한 문서가 대량 포함되어 품질 저하
	- 산술평균 대신 조화평균을 쓰는 이유
		- 두 값 중 더 작은 값에 큰 가중치를 부여하므로, 두 지표 중 하나라도 0에 가까우면 전체 점수가 급격히 하락하여 모델의 결함을 정확히 드러낸다.
	- F1-Score 계산 수식
		- $F_{1} = 2 * \frac{Percision * Recall}{Precision + Recall}$

## 생성 지표와 실패 원인 분석

- 생성 단계 평가 지표 (Generation Metrics)
	- 생성 지표 정의: 인공지능이 최종 출력한 텍스트가 제공된 문맥에 충실한지, 사용자의 질문 의도를 정확하게 충족했는지 검증하는 척도
	- 사실성 (Faithfulness)
		- 개념: 생성된 답변의 모든 내용이 검색기가 가져온 '근거 문서(Context)'에 근거하고 있는지 평가
		- 목적: 환각(Hallucination) 현상 탐별
		- 판정 기준: 답변 문장을 개별 주장 단위로 쪼갠 뒤, 근거 문서에서 증명 가능한 문장의 비율로 수치 도출
	- 답변 관련성 (Answer Relevance)
		- 개념: 생성된 답변이 사용자가 입력한 '질문(Question)'의 핵심 의도에 알맞게 반응했는지 평가
		- 목적: 정보의 참/거짓 여부와 무관하게 엉뚱한 주제를 이야기하는 오류 검출
		- 판정 기준: 문법 완성도나 문장 길이가 아닌, 질문에 대한 직접적인 해결책 제공 여부 평가
- 실패 원인 분석
	- 오류 진단 핵심 원칙
		- 문서를 가져오지 못한 것(검색 실패), 문서를 오독한 것(생성 실패)를 잘 분리해야 올바른 튜닝 가능
	- 검색 실패 (Retrieval Failure)
		- 원인: 청킹 전략 오류, 임베딩 모델 부적합, 낮은 유사도 임계치
		- 주요 증상: 근거 문서 내에 질문에 답할 핵심 내용 누락
		- 개선 방향: 청킹 크기 조절, 하이브리드 검색 도입, Re-ranking 적용
	- 생성 실패 (Generation Failure)
		- 원인: 프롬프트 지시문 모호성, LLM 추론 및 독해 한계
		- 주요 증상: 정답은 명시되어있으나 답변에서 왜곡 및 환각 발생
		- 개선 방향: 프롬프트 제약 조건 강화, 시스템 프롬프트 개선, LLM 변경

## 평가셋 설계 원칙

- 평가 목적 구체화: 단순 사내 안내용인지, 오답 발생 시 치명적인 법률•규정 안내용인지에 따라 검증 강도 결정
- 채점 지표와의 연계: 평가 데이터는 검색 단계의 적합성 지표와 생성 단계의 사실성(Faithfulness), 관련성(Answer Relevancy)를 모두 측정할 수 있도록 구성되어야한다.
- 질의 유형(Query Type) 커버리지
	- 단순 사실 확인: 단일 분서 내에 며잇된 사실을 그대로 확인하는 기본 문항
	- 복합 추론 질문: 둘 이상의 문서 조각을 종합하여 논리적 인과관계를 비교하거나 요약해야 한느 고난도 문항
	- 문서 외 함정 질문: 근거 문서에 정답이 없는 문항으로, 모델이 외부 지식을 임의로 끌어와 거짓말을 하는 '환각(Hallucination)' 현상을 유발하는지 검증

## 평가셋 구축

- 평가셋 데이터 구축 및 구조화
	- 골든셋(Golden Set) 데이터 작성
		- 질문, 모범 정답, 근거 문서를 구조화하고 데이터 누락 여부를 확인하는 단계
	- 골든셋 3대 요소 매칭
		- 질의 유형, 질문, 정답, 근거 문서를 딕셔너리로 구성
- LLM 모델 기반 평가셋 품질 자동 검수
	- 작성된 정답이 근거 문서에 기반하고 있는지 LLM 모델로 자동 교정 및 판별한다.
	- 자동 검수 파이프라인 (Auto-Inspection Chain): LLM 모델을 활용해 평가셋 내 모범 정답이 근거 문서에 부합하는지 검장하는 자동화 구조
	- 결측치 (Missing Value): 입력되지 않고 비어있는 셀로, 정량 평가 실행 전 반드시 0으로 정리되어야한다.

## RAGAS(Retrieval Augmented Generation Assessment) 검색 지표 측정

- RAGAS 검색 평가 지표 원리
	- 2대 기준
		- 정보의 순도 (정밀도)
		- 누락 여부 (재현율)
- 문맥 정밀도 (Context Precision)
	- 개념: 검색된 문서 묶음 중 질문의 정답 도출에 실제 기여하는 유의미한 문서가 상위에 잘 위치하는지 측정
	- 특징: 불필요한 노이즈 문서가 섞여 있거나 핵심 문서가 아래 순위로 밀려날수록 지표 점수 하락
- 문맥 재현율 (Context Recall)
	- 개념: 모범 정답(Ground Truth)을 완성하는 데 필요한 모든 핵심 근거를 검색기가 빠짐없이 찾아왔는지 측정
	- 특징: 정답 작성에 필수적인 정보가 검색 결과에서 누락될수록 지표 점수가 하락

## RAGAS 생성 지표 측정

- RAGAS 생성 평가 지표 원리
	- 답변 생성 단계의 신뢰성과 유용성을 정량적인 수치로 검증
- 사실성 (Faithfulness)
	- 개념: AI 모델이 생성한 답변이 검색된 참고 문서(Context)의 사실에 근거하여 작성되었는지 측정
	- 측정 방식: 답변을 개별 진술 단위로 분해 한 후, 각 진술이 제공된 문서 내용으로부터 사실 확인이 가능한지 검증
	- 특징: 문서에 명시되지 않은 허위 사실을 지어내는 환각이 포함될수록 점수 하락
- 답변 관련성(Answer Relevancy)
	- 개념: 생성된 답변이 사용자가 최초로 질문의 목적과 의도에 얼마나 부합하는지 측정
	- 측정 방식: 생성된 답변을 바탕으로 역방향 질문을 생성한 후, 원 질문과의 <mark>임베딩 유사도</mark>를 계산하여 점수 도출
	- 특징: 제공된 문서에 부합하는 사실이더라도, 원래 질문과 상관없는 내용을 서술하면 점수 하락
- 심사위원 모델 (LLM as a Judge): 객관적 지표 채점을 위해 프레임워크 표준 인터페이스를 거쳐 평가 작업을 전담하는 고성능 언어 모델

## 검색 실패 분석

- 검색 실패 판단 기준
	- 모범 정답을 포괄하지 못하거나(낮은 재현율), 무관한 문서가 상위에 노출(낮은 정밀도) 되는 병목 지점 분류
- 3대 핵심 원인
	- 청킹 실패 (Chunking Failure)
		- 문서 분할 과정에서 정답 정보가 여러 청크로 쪼개진 경우
		- 청크 크기(Chunk Size)를 확장하거나 청크 간 중첩 구간(Chunk Overlap)을 을려 문맥 단절 방지
	- 임베딩 및 어휘 불일치 실패 (Embedding Failure)
		- 문서 내 정확한 정답이 있으나 `top_k`에 진입하지 못한 경우
		- 도메인 특화 임베딩 모델 사용 혹은 키워드 검색과 결합한 하이브리드 검색 구축
	- 메타데이터 필터링 실패 (Metadata Filtering Failure)
		- 작성 연도, 적용 부서, 문서 분류 등 메타데이터 조건 처리가 누락된 경우
		- 메타데이터 추출 규칙 보강, 검색 쿼리에 필수 속성 필터링 강제
- 검색 실패 분석 (Retrieval Failure Analysis)
	- 정량적 검색 지표가 미달된 사례를 추출하여 청킹, 임베딩, 메타데이터 중 결함이 발생한 지정을 찾아내눈 공정
